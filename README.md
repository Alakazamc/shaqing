# 杀青 · 人生短剧模拟器

> 你过的不叫日子，叫片场；你活的不叫人生，叫剧本；死了不叫死，叫**杀青**。
> 游戏打分打的是这部"人生短剧"好不好看——不是你过得好不好，也不是你过得有多惨。

纯静态网页游戏，零构建零依赖零广告：**双击 `index.html` 即玩**（手机浏览器同理，竖屏优先）。

## 玩法（60 秒上手，无需教程）

1. **开拍** → 天赋十连抽选 3（负面天赋才有节目效果）
2. **配点** → 颜/智/体/钱/乐 五维分 20 点（有一键梗模板）
3. **点击过人生** → 长按连点 / 自动播放；金色机缘、危机抉择、十年路牌、特质三选一
4. **五大劫** → 高考(手速QTE)/求职/相亲/35岁/病床，你的全部积累逐项拍入算分
5. **杀青** → 生成电影海报：片名+类型+票房+评分+经典台词+演职员表，一键保存/复制
6. **轮回** → 票房换轮回点数，小卖部买下把的运气；继承 1 个天赋；收集死法图鉴

隐藏内容：**10 条隐秘轨道**（修仙/电竞/富豪/鹤岗/偶像/规则怪谈/说唱/谷子/魔法/AI赛博），入口以"机缘"形态出现，
触发条件玩家不可见——论坛攻略会替你把它们挖出来。

## 运行

```
双击 index.html          # Windows/macOS/Linux 任意浏览器
或 python -m http.server # 可选：起个静态服务
```

## 测试（Node ≥ 18，无依赖）

```
node test/validate.mjs        # 内容校验：schema/唯一性/红线词/年龄覆盖
node test/simulate.mjs 500    # 无头模拟 500 局，输出验收指标
```

模拟验收基线（500 局）：零失败；评分均值 6.0 / 最高 9.7；票房均值 ~37 亿 / 最高 180+；
每局决策 ~20 次；平淡压缩 ~2.3 次/局；死法图鉴覆盖率 70+/72。

## 架构

```
index.html            入口（无构建，全局脚本直载）
src/engine/engine.js  状态机+事件池+大劫+打分+片名生成（无 DOM，可 Node 直跑）
src/ui/app.js         界面控制器（选角/文本流/弹幕/决策/海报页）
src/ui/poster.js      杀青海报 Canvas 绘制（emoji+文字，零素材）
src/ui/sfx.js         WebAudio 合成音效（默认关，摸鱼友好）
content/*.js          全部内容数据：事件/天赋/死法/危机/路牌/特质/大劫/轨道/弹幕/梗
test/                 无头测试（loader/simulate/validate）
docs/                 设计文档：research/(调研) design/(正典+玩法细则)
```

设计宪法（docs/design/00-canonical.md）：纯点击、永不加广告、规则零教学、
单局 2-4 分钟、梗三层词库、内容红线（od 含蓄化/不美化/人物不是笑点）。
