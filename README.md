## 🎮 60 秒上手

1. **选角** —— 天赋十连抽选 3（负面天赋才有节目效果）；开机会给你的主角起一个名字
2. **配置** —— 颜/智/体/钱/乐 五维分 20 点（梗模板一键配点：牛马模板 / 躺平大师 / 赌狗必输）
3. **开拍** —— 点击过人生。**小事是瞬间、大事占一年**；金卡传说自动放慢让你读完
4. **抉择** —— 危机 / 十年路牌 / 特质三选一 / 大劫，间隔至少 2 年，不连轰
5. **大劫** —— 高考是 5 秒手速 QTE，求职/相亲/裁员/病床是算分演出，你的全部积累逐项拍入
6. **杀青** —— 电影海报：片名 + 类型 + 票房构成 + 经典台词 + 演职员表，一键保存/复制
7. **轮回** —— 票房换轮回点数；继承 1 个天赋；收集死法图鉴；集齐 5 条轨道结局解锁 **🥂 杀青宴**

全程纯点击 · 无教程 · 单局 3-5 分钟 · 默认静音（摸鱼友好）· 顶部常驻信息板（五维条+命运chips）零点击全知

## ✨ 五层玩法

### 🎭 多线剧本系统
15 条跨越数年的连续故事：**高考全本**（分科→一模→QTE→出分→复读/进厂/闯社会→多年后的考场回声）、**初恋全本**（停电夜的表白→异地抉择→十年后同学会）、发小、父母、职场、走红、婚姻、病榻、执念、安家、单干、远行、师徒、写作、邻里。选择会在多年后被具体点名——借过网贷的人 30 岁能跑路鹤岗。

### 🎬 电影化包装
死亡=杀青，结算=海报。片名生成器（`《37秒女帝》`/`《修仙从戒网瘾开始》`）、票房公式（基础盘 × 振幅 × 贯彻）、豆瓣式开分、假排片位（"本周排片第 4897 位，排在汪汪队之后"）、人生足迹演职员表。

### ⏱️ 时间与节奏引擎
**瞬间事件**不占年份（一年可以挤好几件小事），**大事占满自己的年份**；阅读停顿分级（传说 2.4s / 史诗 1.9s / 普通 1s）；抉择之间至少隔 2 年；每幕有自己的密度参数；51 岁"半生回望"回收前半生高光。

### 📊 状态零黑盒
顶部常驻信息板：五维数值条 + 命运 chips（轨道深度/执念进度/恋爱负债）+ 阵容特质；事件流是**剧本条时间轴**（年龄轨 + 类型徽章 + 抉择配对）；📊 演员档案一点全知（六格轨道深度/人生足迹）。

### ⚔️ 传播与 meta
同题挑战链接（seed + 战绩，纯静态无后端）、死法图鉴 102 种、称号 18 个、成就 15 项、轮回小卖部、导演阴阳怪气（死亡 50 次："外卖在楼下，先吃饭吧"）。

## 🚀 快速开始

```bash
# 方式一：什么都不装
双击 index.html

# 方式二：本地服务（可选）
python -m http.server 8080
```

测试（Node ≥ 18，零依赖）：

```bash
node test/validate.mjs        # 内容校验：schema/唯一性/红线词/旗标完整性
node test/simulate.mjs 800    # 无头模拟：随机玩 800 局输出平衡指标（含 undefined 文本哨兵）
node test/arcstats.mjs 500    # 剧本触发率：各条多线剧本的入口/分岔/结局到达率
```

## 🏗️ 架构

```
index.html            入口（无构建，全局脚本直载）
src/engine/engine.js  状态机+剧本队列+时间模型+打分+片名生成（无 DOM，Node 可直跑）
src/ui/               界面控制器 / 剧本条渲染 / 海报 Canvas / WebAudio 合成音效
content/              全部内容数据（事件/剧本/天赋/死法/危机/轨道/称号/梗）
test/                 无头测试（loader/simulate/validate/arcstats）
docs/                 设计文档 + 截图
```
