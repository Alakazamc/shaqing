# 借鉴清单：每个乐趣化学物质及其微创新

> 用户授权：可以"抄袭"成熟玩法做微创新。本文逐个登记：来源游戏 → 它真正的乐趣化学物质
> （不是它的题材）→ 原样照抄会怎样 → 我们的微创新。与 `10-gameplay-core.md` 配套。

## 0. 先说清楚"好玩"的化学拆解

一款 2-4 分钟一局的点击游戏要好玩，必须在下列物质里至少命中 6 种，且每种都有
明确的系统载体。任何"感觉好玩"但写不出载体的设计一律作废：

| # | 乐趣化学物质 | 一句话定义 | 本作载体 |
|---|---|---|---|
| F-a | 变率期待 | 下一次点击可能出大事（老虎机原理） | 年卡翻牌+稀有度光效+机缘金闪 |
| F-b | 轻决策重量感 | 决策次数少、次次都在高点 | 危机触发式选项+十年路牌 |
| F-c | 构筑表达 | 这条命是"我的" | 天赋draft+路牌+轨道承诺 |
| F-d | 数字奇观 | 某个时刻数字爆炸式演出 | 大劫算分+票房滚动 |
| F-e | 幽默密度 | 平均5-15秒笑一次 | 事件梗文本+反话UI |
| F-f | 收集完成欲 | 图鉴/成就/解锁勾人回来 | 死法图鉴+作品架+轨道结局 |
| F-g | 好奇心 | 那扇门后面有什么 | 隐秘轨道入口（奇遇形态） |
| F-h | 叙事反讽 | 结局回收前面的铺垫 | 死亡回收动画+反讽评分 |
| F-i | 禁忌快感 | 安全地体验"不该过的人生" | 暗黑轨道（红线内含蓄呈现） |
| F-j | 社交货币 | 产出物替玩家说话 | 杀青海报+经典台词 |

## 1. 人生重开模拟器 → 取三件传家宝

**抄**：开局抽卡+加点（60秒幻想期，2亿人验证过）；文本流节奏（点击=拉杆）；
每轮继承1天赋（跨局攒目标的根源）。
**原样照抄的问题**：中期无事发生的年份连点十几次"你上小学了"，玩家在此流失；
进局后零决策导致"我的命不像我的"。
**微创新**：无事年份自动压缩叙述（见10 §5）；决策集中到危机与路牌（见12）。
**不抄**：纯随机的一切（保留随机骨架但加 agency 三层）。

## 2. 老虎机 / Cookie Clicker 金曲奇 → 点击本身的变率奖励

**抄**：变率强化程序（variable-ratio reinforcement）——奖励不可预测时，行为最顽固。
**原样照抄的问题**：金曲奇是纯 Idle，没有叙事。
**微创新（ME-1 机缘金闪）**：每次点击过年，约 1/40 概率下一年是机缘年——
点击瞬间先给金色闪光（0.4s 前兆），再翻开内容：横财/贵人/轨道入口/离谱奇遇。
**点击这个动作本身挂上了变率奖励**，这是人生重开没有的：原作的点击只是翻页。

## 3. 老虎机灯先行 → 稀有度前兆光效（ME-2）

**抄**：拉杆前滚动的灯光——期待感出现在结果之前。
**微创新**：年卡翻开前 0.3 秒显示稀有度光晕（灰/蓝/紫/金）。玩家先看到"金卡！"
再读内容——**期待先于信息**。同一事件文本，光效让它的情绪价值翻倍。
这直接把"读文本"改造成"开卡"。

## 4. Reigns → 决策张力，但只借它的"压力时刻"

**抄**：数值逼近危险时决策才有重量。
**原样照抄的问题**：Reigns 每张卡都要决策——90年人生=90次决策，决策疲劳+变成做题。
**微创新（ME-3 危机触发式决策）**：决策不是均匀撒的，是被五维危险区触发的：
钱逼近-3 → 债务危机链；快乐触0 → emo链（含蓄线）；体质逼近2 → 健康危机。
平时零决策纯看戏，危机时 UI 变色、必出 2-3 个梗选项。
**决策密度与戏剧张力自动对齐**——这是对 Reigns 和人生重开的双向微创新。

## 5. 杀戮尖塔 → 地图，但把它降维成"路牌"

**抄**：路线选择塑造构筑方向；每层走法是风险偏好表达。
**原样照抄的问题**：StS 的地图是节点图，需要理解战斗/商店/篝火的收益差——超预算。
**微创新（ME-4 十年路牌）**：每逢 10 的年龄，出一张"路牌"：2-3 个十年主题
（卷王十年/发疯十年/搞钱十年/躺平十年/家庭十年……），一行梗文案说明，
点了就给下一个十年定事件池权重。**地图系统压缩成一次点击**，
但"这条命是我规划的"的表达感完整保留。

## 6. Balatro → 只取算分演出，不取牌库管理

**抄**：分数逐项拍入的演出（chip×mult 弹跳）——数字奇观的行业标准。
**原样照抄的问题**：手牌/弃牌/商店——全部超出"纯点击"宪法 C3。
**微创新（ME-5 大劫算分）**：章末大劫（18高考/22求职/28相亲/35裁员/60病床） =
一屏演出：你的五维+天赋+轨道深度作为"手牌"自动逐项拍入
（基础分→【学神】×2.0！→【家教好】+15→达标线动画），玩家全程只看不操作，
但每一项都是他前 20 年攒下的——**爽感来自"我攒的东西在发光"**。
结果不判死，判分支：过=新剧情域，不过=更烂但更精彩的分支。

## 7. Wildermyth → 钩子系统（角色长出自己的故事）

**抄**：人物被事件打上"钩子"特质，后续自动长出专属剧情线。
**微创新**：FLAG 系统即钩子（危机选项写入 flag → 后续事件域解锁）。
24岁选了[借网贷] → 30岁路牌会多出一个[跑路]选项 → 鹤岗轨道入口概率上升。
玩家从攻略帖读到的是剧情语言："借过网贷的人 30 岁能跑路鹤岗"——暗线明放。

## 8. 羊了个羊 → 分享即功能 + 反话文案

**抄**：把传播做进流程（不分享就拿不到东西）；稀缺感文案（0.01%）。
**微创新**：海报是流程必经节点（不能跳过）但分享行为完全自愿；
反话文案（"超过3%的观众""本周排片第4897位"）给截图加梗。
**不抄**：强迫分享解锁道具——会触发平台反感，且与"永不加广告/不设墙"冲突。

## 9. 苏丹的游戏 → 机制即叙事 + 禁忌快感（红线内）

**抄**：让机制承载道德重量：大劫的"达标线"逼你在天赋和人格之间做选择
（高考大劫前把体质换成智力=把自己改造成做题家——机制本身在讽刺）。
**微创新**：暗黑轨道（od/地雷/围城）不做成机制惩罚也不做成奖励，
做成**叙事轨道**——它的"收益"是独占结局称号和台词（F-i 禁忌快感的合法出口）。

## 10. 电子木鱼 / Inscryption → 点击的禅意 + 表皮下的秘密

**抄**：电子木鱼——纯点击可以有正反馈（功德+1 的视觉脉冲）；
Inscryption——游戏表皮之下藏着另一层（meta 悬念）。
**微创新**：每次点击五维条有微小脉冲反馈（手感）；海报墙里混着"尚未拍摄"的
空海报框（某轨道结局的剪影）——收集欲望可视化。

## 11. 短剧公式 → 节奏表

**抄**：前3秒钩子/每10分钟反转/结尾回收伏笔（F10，已在正典 §3）。
**微创新**：把"集"映射为"十年"，反转槽就是大劫，付费卡点换成**死亡回收**——
观众留下来不是因为付费墙，是因为想看自己这条命怎么收场。

## 12. 明确不抄的（负面清单）

| 来源 | 不抄什么 | 原因 |
|---|---|---|
| Balatro | 商店/弃牌/手牌 | 违反 C3 纯点击 |
| Reigns | 全卡决策 | 决策疲劳 |
| BitLife | 菜单式模拟 | 太重，传播形态弱 |
| 星野/猫箱 | AI 对话 | 无目标感，留存崩（调研§9） |
| 苏丹 | 强制死亡倒计时 | 与"看戏"节奏冲突 |
| 原作 | 纯随机无 agency | 中期流失根因 |
