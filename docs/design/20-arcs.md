# 剧本系统（ARCS）：多线叙事设计【已实现】

> 用户裁决：先设计庞大的多线剧本，再塞进游戏。本文是剧本大纲与实现合同。
> 上位约束：ME-0（机制不可见）——玩家看见的是"故事发生了"，永远看不见"剧本线触发中"。

## 0. 诊断：广度 ≠ 深度

现状 1005 条事件 = 1005 个孤立瞬间。现有的"影响后面"只有危机选项和 42 个孤立分支，
选择之后的世界没有回声；高考大劫一闪而过。
**玩家要的不是更多瞬间，是"连贯的故事 + 选择后世界真的变了"。**

## 1. 核心概念：剧本（Arc）

一条剧本 = 一段跨越数年的连续故事，由**链式事件**构成：

```
入口(Entry) → 节拍1 → [选择分岔] → 节拍2a/2b → … → 收束(多结局之一) → 尾声回声
```

- **实现零新系统**：全部用现有 DSL——节拍 N 用 `inc:{f:['arc_prev']}` 挂在节拍 N-1
  的 `flag`/`br[].f` 上。引擎只加一条**叙事动量规则**（见 §2）。
- **ME-0 合规**：玩家看到的是"隔壁班那个人"和"十年后的同学会"，不是"初恋线 3/7"。
- **引擎动量**：所有 `inc.f` 门控的事件在条件满足时权重 ×5——旗标一亮，剧本
  一两年内必然续演，不会断线。入口节拍权重 w:3-4（自然偶遇感）。

## 3. 大劫改造：从"一闪"到"三幕"

每个大劫 = **前幕（铺垫节拍）→ 大劫本幕（QTE/算分）→ 后幕（余波 1-2 节拍）**：

| 大劫 | 前幕 | 本幕 | 后幕 |
|---|---|---|---|
| 高考 18 | 高三百日（分科/一模/家长会 3 拍） | QTE | 出分夜→志愿→大学第一课/复读抉择（3 拍） |
| 求职 22 | 秋招海投 1 拍 | 算分 | offer 抉择/入职第一课（2 拍） |
| 相亲 28 | 家里的照片攻势 1 拍 | 算分 | 按结果分流到婚姻线（2 拍） |
| 裁员 35 | 风声 1 拍（自救/死守选择） | 算分 | 空窗期/新起点（2 拍） |
| 病床 66 | 一次晕眩预兆 1 拍 | 算分 | 康复训练/长期共存（2 拍） |

大劫本幕的 `rt` 文本全部扩为 2-3 句（现场感），并新增后幕节拍（flag 门控，动量 ×5）。

## 4. 分岔写作规范

- 每处分岔 2-3 项，**没有明显最优解**（每项各写 FLAG/TAGS 通向不同后续）；
- 分岔后果必须在 ≥1 个后续节拍中被**具体点名**（不是泛泛的属性加减）；
- 每条剧本至少一处"多年后的回声"节拍（毕业十年/婚礼现场/老同学会）；
- 拒绝线也要写完（遗憾是合法且必要的结局，配反讽评分加成）。

## 5. 与既有系统的关系

- 轨道（10 条）= **天赋型长线**（奇遇触发、贯穿一生）；剧本 = **际遇型中线**（3-20 年、必终结）；
- 危机 = 单点张力；剧本 = 弧光。三者共享 FLAG/TAGS 底座，互不抢事件池
  （剧本节拍高权重但 once:true，不重复占位）。
- 死亡反讽池新增：剧本旗标作为反讽源（如初恋线 `lo_miss` + 老年孤独死法 → +反讽）。

## 6. 实现状态（已落地）

- 引擎：叙事动量（inc.f 权重 ×12）+ **剧本队列**（旗标写入即入队，
  次年强制续演，窗口外留队等年龄 +2 年宽限；队列在危机/特质之前触发）；
  入口节拍用 `story: true` 标记（权重 ×30，豁免稀有度税）。
- 内容：8 条剧本已入池（arcs-boss/love/life/misc.js），事件总量 1079；
  大劫 rt 全部扩为多句 + 结果旗标 + 后幕节拍。
- 统计脚本：`node test/arcstats.mjs 500`（各线入口/分岔/结局到达率）。
- 调参结论：入口触发率 40-90%（人生必然时刻更高），38% 的局能走完
  至少一条剧本的结局/回声；决策 28-30 次/局。
