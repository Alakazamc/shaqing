# 手感与演出（Juice Spec）

> 零美术资产（C8）约束下的爽感工程。原则：**所有爽感来自时序、动效与文案，不来自素材。**

## 1. 点击手感

- 每次点击：五维条轻微脉冲（scale 1.02, 120ms）+ 年卡翻转（rotateY 90°, 180ms）。
- 长按连点：150ms/年，普通年文本快速滚动（每屏保留最近 3 行，旧行上移淡出）。
- 自动播放：1.2s/年；机缘/危机/路牌/大劫自动暂停。
- 音效默认关（C2 摸鱼隐蔽性），右上角一键开关；音效用 WebAudio 合成（无素材）：
  翻卡"嗒"、稀有"叮"、机缘上滑音、危机低鸣、大劫鼓点、票房滚动的机械声。

## 2. 稀有度光效（ME-2 期待先于信息）

| grade | 光晕 | 时序 |
|---|---|---|
| 0 普通 | 无 | 直接显示 |
| 1 稀有 | 蓝色 0.3s | 先晕后文 |
| 2 史诗 | 紫色 0.4s + 微震屏 | 先晕后文 |
| 3 传说/机缘 | 金色 0.5s + 全屏暗角 | 点击瞬间出晕，悬念峰值后翻文 |

规则：**晕到文的间隔即期待时长**，随稀有度递增（0/0.3/0.4/0.5s）——
玩家会学会"见金就坐直"，这是纯 UI 制造的多巴胺。

## 3. 大劫算分演出（ME-5）

- 达标线动画先出现（"一本线 26"横杠从左滑入）。
- 逐项拍入：基础分（五维）→ 天赋逐张（每张 300ms，拍入时 chip 弹跳，
  增益项配 `+8`/`×1.5` 浮字，天赋 emoji 放大闪现）→ 轨道加成 → 总分 vs 达标线。
- 结果揭示：过线→横杠变绿+印章"上岸"；差一点→"差 X 分"大字（差 1-3 分额外弹
  "就差一点！！"，这是最强的情绪时刻，必须单独调演出）。
- 全程玩家只点一次"开始结算"，其余自动。

## 4. 死亡与票房结算

- 死亡行固定格式（10 §6），出现后全屏淡黑 400ms（唯一的"庄重时刻"）。
- 票房计数器：基础/振幅/贯彻三个因子逐个拍入（同大劫演出语系），
  数字滚动 800ms 收在最终值；百亿以上触发金色撒花（CSS emoji 粒子，无素材）。
- 评分开分：豆瓣梗——"开分 8.2"+ 一条短评自动生成（从经典台词池取）。

## 5. 海报（Canvas 竖版 9:16）

- 结构（自上而下）：片名（大字，竖排可选）→ 类型徽章 → 3-5 条高光时间线
  （带 emoji 前缀）→ 经典台词（引号+署名"——本片主演：你"）→ 演职员表 →
  票房/评分/排片位（反话文案）→ 底部"杀青大吉"印章。
- 高光时间线选择：出生 / 最高 grade 事件 / 轨道里程碑 / 大劫结果 / 死法。
- 配色由 TAGS 决定（电竞=蓝紫 / 富豪=金 / emo=黑白粉 / 怪谈=红黑）——
  海报自带圈层气质，圈内人一眼认出（F-j）。

## 6. 反话文案池（F9，持续扩充）

- 排片位："本周排片第 4897 位，排在《汪汪队立大功大电影》之后"
- 评分对比："超过 3% 的观众" / "低于 97% 的观众（恭喜）"
- 轮回文案："轮回点数+14，够下辈子抽一次保底"
- 假票房榜：混入真实感假片名（《爱你把我灌醉2》《重案六组之退休风云》），
  玩家的片子插在中间——截图传播点。

## 7. 性能与实现注意

- 全部动效 CSS/Canvas 实现，无图片；粒子上限 40；
- 低端机（残旧安卓 WebView）降级：关闭震屏与粒子，保留时序（爽感来自时序不来自粒子）。
- 所有演出时长预算合计 ≤20s/局（A8：死亡→重开 ≤20s）。
