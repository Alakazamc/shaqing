# 核心玩法循环 v2（好玩性优先版）

> 上位依据：正典 `00-canonical.md`（隐喻/宪法/打分不变）+ `11-borrowed-fun.md`（ME-1~ME-5）。
> 本文回答一个问题：**玩家凭什么在第 47 次点击时还不腻？**
> 本文的最终验收标准见 §7，任何实现不满足即为返工。

## 0. 机制不可见原则（ME-0，最高原则）

v1 的死因是玩家看得见机制（牌/槽位/赛季）。本作反其道：
**玩家永远在过人生，永远看不见系统。**

- 看见的是剧情：路牌长成"你的 30 岁要怎么过？"，危机长成"花呗还不上怎么办"。
- 看不见的是机制：权重、条件池、TAGS、达标线公式。
- 无任何"规则/帮助/图例"面板。攻略帖里流行的是内容语言（"借过网贷的人 30 岁能跑路"），不是系统语言（"flag:debt 解锁 track:hegang"）。

判断标准：把任意一屏截图给没玩过的人看，它必须像一张聊天记录/一部短剧的字幕，不能像一张系统界面。

## 1. 一局的完整骨架（时长预算 2-4 分钟）

```
[海报墙/片名页] 3s      —— 上一世海报可再看，大按钮【开拍】
[选角] 20-30s           —— 天赋10连抽：牌背一排，逐张点击翻开（0.15s/张），
                           选3；负面天赋混在其中（原作验证：喜剧+combo）
[配置] 10-20s           —— 五维各3点+20自由点；提供梗模板一键配点：
                           【牛马模板】【天才少年】【躺平大师】【赌狗必输】…
[开机·拍摄中] 90-150s   —— 核心循环（见§2）
[杀青] 15s              —— 回收动画+海报
[轮回] 5s               —— 点数结算+继承，一键再来
```

## 2. 拍摄中的微观循环（每 2-8 秒一个节拍）

玩家做的唯一动作：**点击（或长按连点/自动播放开关）**。每点击一次 = 过一年。

```
点击 → 年卡翻开
  ├─ 0.3s 稀有度光晕先行（灰/蓝/紫/金）← ME-2 期待先于信息
  ├─ 普通年：一行灰字（"你上小学了"）
  ├─ 稀有年：一行彩字+轻震动（"你把补习费全部买了干脆面，抽中了一张闪卡"）
  ├─ 机缘年(≈1/40)：点击瞬间金闪 ← ME-1，横财/贵人/轨道入口
  ├─ 危机年：五维进入危险区时必触发 ← ME-3，UI 转红，出2-3个梗选项
  ├─ 路牌年(逢10)：十年主题2-3选1 ← ME-4
  └─ 大劫年(18/22/28/35/60)：算分演出 ← ME-5
五维条随每次点击微微脉冲；逼近危险区时抖动+变黄
连续3+年无事 → 自动压缩成一句"岁月快进"文案 ← §5
```

**为什么要节拍化**：人生重开的中期流失发生在"连点 20 次没动静"。
本作的每一节拍必属六种之一（普通/稀有/机缘/危机/路牌/大劫），密度预算见 §7。

## 3. 三层 agency（v2 版决策预算 ~13±3 次/局；v3 修订见 14-fun-v3.md：+特质三选一 4-6 次，每次≤3秒）

| 层 | 时机 | 次数 | 玩家看到的 | 系统做的事 |
|---|---|---|---|---|
| 幻想层 | 开局 | 2 | 抽卡、配点 | 定初始 TAGS/TOKEN |
| 路线层 | 逢10岁 | 6 | 十年路牌 | 改下一个十年的事件池权重 |
| 应变层 | 危机/机缘 | 4-6 | 人生抉择 | 写 FLAG、开/关轨道门 |
| 成长层(v3) | 里程碑/稀有事件后 | 4-6 | 特质三选一 | 挂被动特质，大劫时拍入演出 |

决策全部发生在剧情高点（危机、路牌、机缘），平时零负担。
**决策少而重（F-b）+ 构筑表达（F-c）同时成立**，且不违反 C3 纯点击。

## 4. 五维的角色：不是资源，是保险丝

- 钱逼近 -3：债务危机链（催收/找爸妈/跑路——跑路是鹤岗轨道入口之一）
- 快乐触 0：emo 链（含蓄线，选项之一"跟朋友说了"写 flag:someone_there，后续解锁被拉一把的文本）
- 体质逼近 2：健康危机（体检报告/住院/硬扛——硬扛+没钱=死亡链）
- 颜值/智力进入高位（≥9）：**机会预警**（金色而非红色）：星探搭讪/竞赛邀约——轨道入口的主要来源
- 五维高位不设上限惩罚（不做 Reigns 的双向爆表死——那是权力游戏的隐喻，不适合人生）

**大劫是五维的总决算**：18 高考/22 求职/28 相亲/35 裁员/60 病床，五维+天赋+轨道深度
逐项拍入算分（演出见 13 §3），结果判分支不判死。

## 5. 节奏保真：压缩与反压缩

- **压缩（正向快进）**：连续 3+ 年全部普通 → 合并为一句快进文案
  （"接下来的五年平淡如水，你甚至想不起来自己干了什么"），点击一次跳过整段。
  无聊不被呈现，被叙述。
- **反压缩（钩子）**：章末固定出钩子文案（"你以为这就完了？"式）+ 下一章预告式一行
  （"18 岁的夏天，高考成绩即将揭晓"），保留期待。
- **反转槽**：每个十年至少一个稀有/史诗事件保底（权重补偿：若该十年稀有出勤不足，池子加权）。

## 6. 死亡与海报（每局的收束爽点）

死亡触发：STR 死亡链 / 意外池 / 寿命 / 剧情线。
1. **回收动画**：死亡前一行固定格式（"第 31 年，你的故事迎来了结局。"），
   死法优先匹配铺垫（反讽池：天赋/flag/轨道呼应）。
2. **杀青海报**：票房计数器滚动（基础×振幅×贯彻逐项拍入——Balatro 式收尾）、
   评分开分（豆瓣梗：开分 X.X，"超过 3% 的观众"）、片名、经典台词、演职员表。
3. 海报即重开页：【再拍一部】永远在底部 20% 处常驻，无任何结算摩擦（C5）。

## 7. 验收标准（可量化，实现后逐条打钩）

| # | 标准 | 度量 |
|---|---|---|
| A1 | 30 秒内笑一次 | 出生-3岁段必有 ≥1 个 grade≥1 事件；抽卡阶段文案自带梗 |
| A2 | 平均 5-15 秒一个节拍事件 | 逐分钟日志：普通年连续出现 ≤3 次必被压缩 |
| A3 | 一局决策 13±3 次 | 路牌 6 + 危机 4-6 + 机缘承诺 ≤2 + 开局 2 |
| A4 | 单局 2-4 分钟 | 自动播放模式下中位数 ≤3.5 min |
| A5 | 每局有一个"我的"故事 | 杀青海报片名可区分度：同配置双跑片名不同率 ≥80% |
| A6 | 爽感峰值 ≥2 次/局 | 大劫算分 + 票房滚动 + 反讽回收，至少 2 次全屏演出 |
| A7 | 零教学 | 无规则面板；新玩家首局完成率（埋点）≥90% |
| A8 | 死亡→重开 ≤20 秒 | 回收+海报+轮回结算的动画总时长预算 |
