## 0. 一句话与总隐喻

**《杀青》—— 人生短剧模拟器。**
你过的不叫日子，叫片场；你活的不叫人生，叫剧本；死了不叫死，叫杀青。
游戏给你的不是"人生评分"，是**这部电影的成绩单**：票房、评分、片名、经典台词。
你要的不是好人生，是一部好看的戏。

总隐喻的所有推论（必须全部成立）：
| 人生概念 | 片场概念 | 系统落点 |
|---|---|---|
| 出身/天赋 | 剧组配置/演员阵容 | 开局抽卡+加点（60 秒幻想期） |
| 活着 | 拍摄中 | 点击推进的文本流 |
| 死亡 | 杀青 | 结算触发器 |
| 人生总结 | 电影海报（杀青海报） | 唯一的传播物 F4 |
| 人生质量 | 票房+评分 | 打分系统（故事性，非生活性） |
| 天赋 | 演职员表 | 海报署名区 |
| 隐藏轨道 | 禁片/ cult 经典 | 隐藏内容工程 F5 |
| 再来一局 | 重开新戏 | 轮回 meta F6 |

## 1. 硬约束（宪法，违反即返工）

1. **C1 纯静态网页**：零构建、零依赖、双击 `index.html` 即跑；手机竖屏优先。不用框架（UI 是追加式文本流， vanilla足够）。
2. **C2 永不加广告**（原作作者之怒，见 benchmark §1）：核心循环内无任何广告位与跳转。
3. **C3 全程点击**：抽卡点击、加点点击、过年点击（含长按连点/自动播放开关）、选项点击。无键盘需求、无滑动需求、无拖拽。
4. **C4 规则零教学**：一切机制通过内容与梗自解释；不得出现"教程/帮助"面板。玩家 30 秒内必须已经在笑。
5. **C5 单局 2-4 分钟**：从点击"出生"到杀青。重开无结算动画拖延，海报页就是重开页。
6. **C6 内容红线**：`03-subculture.md` §3 四原则（od 含蓄化、地雷系不美化、跨性别不猎奇、靶子永远是环境）。红线写入事件校验脚本，违规文案 CI 不过。
7. **C7 梗分层**：L1/L2/L3 三层词库（03 §1），L3 只进替换槽。事件文本用 `{lex:...}` 占位符引用词库，不写死。
8. **C8 零美术资产**：emoji 即美术。海报用 Canvas 排 emoji+文字。无 png/svg/字体。

## 2. 状态模型（比 v1 砍掉 70%）

### 2.1 五维属性（沿用原作命名，玩家零学习）
`CHR 颜 / INT 智 / STR 体 / MNY 钱 / JOY 乐`，开局各 3，自由分配 20 点，单项 ≤10，范围 [-5, 20]。
- `STR ≤ 0` → 进入死亡判定。
- `MNY` 是水位档不是货币（负债/温饱/小康/新贵/离谱五档显示）。
- `JOY` 归零不直接死，但触发 emo 事件域（含蓄线）。
- 每年结束记录五维快照 `WLOG[year]`，供振幅计算。

### 2.2 三个叙事轴（v1 的 AUD/HOOK/TROPE 全部废除）
| 键 | 说明 |
|---|---|
| `FLAG[]` | 剧情旗标（事件/选项写入）。事件网暗线的显式载体 F7 |
| `TAGS{}` | 语义标签计数（`rich/broke/fame/love/health/chaos/...`）。反讽与片名用 |
| `TRACKS{id:depth}` | 已入轨道及深度。隐秘内容的进度条 F5 |

### 2.3 meta（跨局）
| 键 | 说明 |
|---|---|
| `REINC` | 轮回点数（票房换算），可花：指定天赋必出池 / 开局+5点 / 抽卡+1次 |
| `INHERIT` | 每局结束继承 1 个天赋（修仙机制的根源，原作验证） |
| `DEATHDEX{}` | 死法图鉴（收集品；目标首发 100+ 死法） |
| `WORKS[]` | 杀青作品列表（片名+票房+评分，本机存档） |

### 2.4 开局四项（局内只读）
`SEX`（含常规+隐藏项；轨道门槛禁止引用性别）、`ORIGIN`（家庭出身）、`PERSONA0`（性格，等价一张天赋牌）、`TALENT[3]`。

## 3. 核心循环

```
[片名页] → 点"开拍" → [选角]天赋十连抽3(可重抽REINC) → [配置]五维加点
  → [开机] 逐年文本流(点击/长按/自动) ；每10年反转槽；稀有选项事件(2-3项,点击)
  → 轨道入口奇遇 → 轨道事件域推进
  → 死亡判定 → [杀青海报]片名/类型/评分/票房/经典台词/演职员表/死法图鉴+1
  → 一键保存海报 / 复制纯文本版(微信群粘贴友好)
  → [轮回] 点数结算 → 继承1天赋 → 回片名页
```

**节奏设计（短剧公式 F10 映射）**：
- 0-3 岁：每年一条；3 岁前必须出现第一件离谱事（黄金三秒）。
- 每 10 年一个**反转槽**：从离谱池抽大事件（中彩票/塌房/拆迁/认亲）。
- 每章末（3/6/12/18/22/30/45/60/75岁）一个**钩子**：章结文案自带下章悬念（"你以为这就完了？"式）。
- 死亡=伏笔回收时刻：死法优先匹配 `TAGS`/`FLAG` 里的铺垫（反讽），命中则评分加成。

**选项事件**：低频（平均每 10 年 1-2 次）、选项本身就是梗（"怼回去/发疯/已读乱回"）、
选项写入 FLAG/TAGS → 影响后续事件网。这是"选择影响后面"的显式层；暗线层靠条件池。

## 4. 事件系统（继承原作 DSL，加三层显式建模）

```js
{ id, age:[min,max], grade:0|1|2|3,        // 0普通/1稀有/2史诗/3传说
  text, lexSlots:[],                        // 文本 + 词库槽位
  eff:{CHR,INT,STR,MNY,JOY,AGE,LIF},        // 效果（同原作）
  inc:{flag:[],tag:[],track:[],dim:{}},     // 前置条件（原作 include 超集）
  exc:{...}, once:bool, noRandom:bool,
  branch:{ optId:{text, eff, flag[], tag[]} } }  // 稀有选项
```

- **grade 金字塔**（对齐原作实测）：普通 60% / 稀有 25% / 史诗 12% / 传说 3%。
  传说级 = 值得截图的事件（3 岁进组拍戏、被雷劈两次、捡到orto阿飘…）。
- **87% 事件带 inc 条件是目标态**（原作实测 87%）：写作工具按当前 FLAG/TAGS/TRACKS
  过滤候选池，作者不靠脑子记状态（原作作者的教训）。
- `noRandom` 分支事件与追加事件（postEvent）沿用原作机制。

## 5. 轨道系统（隐秘内容工程 F5）

首发 10 条，每条 = 一个亚文化圈层 = 一个梗语料域：

| 轨道 | 入口（隐秘） | 结局称号（独占） |
|---|---|---|
| 修仙 | 传说天赋【山里捡的书】+体质≥8 活过 60 | 飞升 / 心魔爆体 |
| 电竞 | 少年网吧奇遇 + INT/反应链 | 世界冠军 / 退役当主播 |
| 偶像 | 练习生招募传单 + CHR | 顶流塌房 / 长红天后 |
| 说唱 | 地下 battle 事件链 | 中文说唱之神 / 广告歌之王 |
| 谷子 | 漫展迷路事件 | 谷圈大佬 / 痛包艺术家 |
| 魔法 | 触碰禁忌之书（克苏鲁） | 大法师 / SAN 归零 |
| 规则怪谈 | 收到一张《员工守则》 | 破局者 / 规则的一部分 |
| 鹤岗 | 灵活就业 + 存款阈值 | 全款拿下 / 反向卷王 |
| AI 赛博 | AI 伴侣App 事件 | 意识上传 / 数字永生失败 |
| 富豪 | 反转槽暴富 + 理财选择 | 泼天富贵接住了 / 归零 |

- 轨道有 5 级深度，深度=该轨道事件域的抽取权重+专属文本解锁。
- 每条轨道独占结局称号进海报片名（"《修仙失败实录》"）。
- 入口全部是"奇遇事件"形态（玩家不知道这是轨道入口，论坛会写出攻略——F5 的攻略传播）。

## 6. 打分系统（故事性，非生活性）

**票房**（整数，单位亿，离谱化显示）= 振幅 × 贯彻
- 振幅 `AMP = 1 + max(WLOG落差)/10`：五维快照的极差驱动。平顺人生 AMP≈1，暴富再归零 AMP 爆炸。
- 贯彻 `DEEP = 1 + Σ轨道深度×0.5`：半途而废的修仙者不如走火入魔的。

**评分**（10 分制，一位小数）= 5.0 + 反讽加成 + 传说密度 + 钩子命中率 - 乏味惩罚
- 反讽：死法与 `TAGS`/天赋呼应（天赋【老当益壮】+ 死于跳广场舞扭到腰 → +2.0）。
- 乏味惩罚：全程无 grade≥1 事件 → 评分向 2.x 塌缩，片名自动变《纪录片：平淡的一生》。

**片名生成器**（传播的核心 F4）：
`《{类型}》{主标题}：{副题}`，由 TRACKS 最高轨道 + TAGS 前二 + 死法 模板拼装。
类型标签：剧情/喜剧/恐怖/悬疑/玄幻/伪纪录片/邪典。副题从死法/反讽模板取。

**经典台词**：从本局文本流按（grade×振幅×选项熵）挑 1 句，海报高亮。

## 7. 杀青海报（唯一传播物，流程必经节点）

Canvas 绘制竖版 9:16，emoji+文字：
- 顶部：片名 + 类型徽章
- 中部：3-5 条高光时间线（出生/最强反转/轨道/死法）
- 演职员表：天赋=主演阵容（emoji 署名）
- 底部：票房 X 亿 · 评分 X.X · "本周排片第 4897 位，排在《汪汪队立大功》之后"
- 一键：保存 PNG / 复制纯文本（微信群直接粘贴的 emoji 文本版）

**反话文案（F9）**：排片位、评分对比（"超过 3% 的观众"）、假票房榜都按反差写。

## 8. 轮回 meta（F6）

- `REINC = 票房/100 + 图鉴新增×5 + 传说事件×10`（向上取整）。
- 花法：天赋定向池（下局必出指定 grade≥2 天赋）/ 开局点数 +5 / 抽卡次数 +1。
- 继承 1 天赋（原作验证的留存钩）。
- 死法图鉴 + 作品列表永远可见——"我离收集完还差 37 种死法"。

## 10. 技术形态

- vanilla JS（全局脚本，无模块——file:// 直开兼容）、无构建。
- 目录：`src/engine/`（状态机+事件池+打分）、`src/ui/`（流渲染+海报canvas）、`content/`（数据 js）。
- 内容校验脚本：`test/validate.js`（node 直跑）——事件 schema、条件引用存在性、红线词、词库槽位、各年龄段覆盖密度。
- 种子随机（mulberry32）：链接带 `?seed=` 可重看同一条人生（P2）。
