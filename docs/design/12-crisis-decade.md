# 危机与路牌：两个决策系统的细则

> 展开 `10-gameplay-core.md` §3/§4。这两个系统承担全剧的 agency（F-b/F-c），
> 写作前必须先定骨架，事件文案按骨架填。

## 1. 危机系统（ME-3 决策张力对齐）

### 1.1 触发规则

| 危机域 | 触发条件 | 语气 | 出口特性 |
|---|---|---|---|
| 债务 | MNY ≤ -3 | 慌张搞笑 | 可开鹤岗轨道门 |
| emo | JOY ≤ 0 | 含蓄温柔 | "跟朋友说了"→flag:someone_there→救赎域 |
| 健康 | STR ≤ 2 | 紧张 | 硬扛+MNY<0 → 死亡链提前 |
| 机会（反向危机） | CHR/INT ≥ 9 | 金色亢奋 | 轨道门主来源 |

- 同一年多域同时触发时只出优先级最高的一条（健康>债务>emo）。
- 危机年必出 2-3 选项；选项全部为梗文案，**没有明显最优解**（各写 FLAG/TAGS，通向不同事件域）。
- 危机可以拒绝解决：给一个"拖"选项（"先摆烂几天再说"）→ 域加深、下一轮再触发——
  摆烂是合法策略但会滚雪球（苏丹式压力，但节奏更缓）。

### 1.2 每域的选项模板（M1 骨架版，后续扩池）

**债务**：
- [找爸妈要] flag:family_net → 域解除，TAGS+family，附带一顿数落文本
- [借网贷] flag:debt_chain → MNY+4 但标记；30岁路牌出现[跑路鹤岗]
- [跑路] → 直接切鹤岗门（MNY<0 才可见）

**emo**（红线：含蓄、不呈现行为细节、出口向）：
- [请假躺一周] JOY+2，慢恢复
- [跟朋友说了] flag:someone_there → 后续解锁"被拉了一把"文本域
- [硬撑] → 加深，再触发时选项收缩——最后仍保留"说"的出口

**健康**：
- [体检] → 分支文案（虚惊/查出来点东西）
- [开始锻炼] STR+2
- [不当回事] → 标记 flag:ignore_health，低 MNY 下死亡链概率显著上升

**机会**（金色）：
- 接 → 轨道门开/属性收益
- 不接 → 一句幽默旁白，TAGS+cautious

### 1.3 红线联动

emo 域与死亡链的全部文案进 `test/validate.js` 红线词表校验（03-subculture §3）：
不得出现方法/药物名/剂量；出口文案必填（每个 emo 事件必须有至少一个"通向继续活着"的选项）。

## 2. 路牌系统（ME-4 十年主题）

### 2.1 结构

触发年龄：10 / 20 / 30 / 40 / 50 / 60（6 次；18/22/28/35/60 由大劫占位）。
每个路牌 = 2-3 个十年主题卡，每卡：**主题名 + 一行梗文案**（这就是玩家看到的一切）。

### 2.2 主题池示例（M2 全量 ≥20 个主题）

| 年龄 | 选项示例 |
|---|---|
| 10 | 【卷学十年】题海是我的海洋 /【发疯十年】社团+网恋+中二病 /【搞钱十年】小卖部倒爷 |
| 20 | 【巅峰十年】往死里卷 /【恋爱脑十年】恋爱大过天 /【躺平十年】提前养老 /【漂泊十年】去大城市 |
| 30 | 【卷王十年】35岁前上岸 /【家庭十年】按部就班 /【单干十年】辞职创业 /【流浪十年】数字游民 |
| 40 | 【守成十年】稳字当头 /【再搏十年】all in /【复兴十年】重新捡起年轻时的梦 |
| 50 | 【保养十年】枸杞保温杯 /【折腾十年】摩托车驾照 /【佛系十年】上香 |
| 60 | 【含饴弄孙】【广场舞之王】【再就业】【回炉重造】 |

### 2.3 效果机制（玩家不可见）

- 选中主题 → 该十年事件池权重 60/25/15 倾斜 + 写 1-2 个 TAGS。
- 主题与轨道联动：轨道承诺后，路牌自动追加该轨道专属选项
  （如电竞承诺后 20 岁路牌出现【青训十年】）。
- 主题文案必须自带梗（"提前养老：你的精神状态已经 60 岁了"）——路牌本身就是笑点（F-e）。

### 2.4 与打分的接口

贯彻分（DEEP）主要由"路牌主题的一致性"驱动：连续选同主题/同轨道 → 贯彻加成；
每十年换一个方向 → 贯彻塌缩（片名会变成《四不像：一个什么都试过的人》）。
这从机制上奖励"人设贯彻"，同时允许"浪子回头"作为反讽池的高分剧本
（贯彻的反向用法：铺垫多次换道后 60 岁的【回炉重造】走通——设计为彩蛋级反讽）。

## 3. 大劫（章末总决算）与两个系统的关系

大劫（18/22/28/35/60）**不是危机也不是路牌**，是无选项的算分演出（玩家只看），
它的"选择"早在之前 10 年的路牌/危机里做完了——大劫只是兑现时刻。
五个大劫的达标线与分支表在 `14-bosses.md`（实现期编写）。
