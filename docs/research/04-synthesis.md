# 综合：什么样的游戏最好，我们做哪个

## 1. 九个案例给"好玩 + 传播"排出的坐标系

把调研过的案例按两个轴摆：**玩家输入深度**（零决策↔重策略）和**传播形态**（自发截图↔功能裂变）：

```
重策略 │ 苏丹的游戏          Reigns
       │ （深但不裂变）       （轻策略+轻传播）
       │
       │ BitLife             ★ 目标区：
轻策略 │ （长青不裂变）       零决策的节奏感
       │                     + 作品型传播
零决策 │ 人生重开模拟器       羊了个羊
       │ （零决策+自发截图）  （零决策+功能裂变）
       └─────────────────────────────
         自发截图              功能裂变
```

**结论 1：目标区是"人生重开的输入模型 × 羊了个羊的裂变自觉 × 苏丹的机制叙事深度"。**
不存在一个案例同时占了三点——这就是机会位。

**结论 2：人生重开验证过的三件套是地基**：
零决策文本流（F3）、总结卡作品（F4）、修仙式隐藏目标+继承（F5/F6）。
推翻这些等于推翻已被 2 亿访问验证的东西。新设计必须是它的升级，不是替代。

**结论 3：旧方案（小丑牌化）失败的结构性原因**（对照 F3）：
- 引入了 CAST/DECK/ROUTE/TROPE 等 10+ 状态字段和构筑决策 → 玩家要"学"和"管"，
  违反 F3 和禁令 X3（30 秒规则学习上限）。
- 计分牌把传播素材从"离谱人生文本"变成"数字/卡组截图"，违反 F4。
- 它是"设计师的游戏"，不是"群友的玩具"。

**结论 4：升级点按证据排序**：
1. **总隐喻统一**：每条人生 = 一部短剧（借短剧公式的势，2023-2026 最热的叙事消费品）。
   死亡=杀青，总结卡=海报，评分=票房+评分，天赋=演职员表。
   这个隐喻把 F4 的"作品"从抽象要求变成具体形态。
2. **暗线明放**：原作 87% 前置条件的暗网保留，但设计端显式建模（轨道/旗标/标签），
   玩家端半显式（轨道入口可见为"奇遇"，走向靠积累，攻略可写）。
3. **节奏工程化**：短剧公式（F10）直接映射到年龄轴。
4. **裂变功能化**：杀青海报是流程必经节点，一键复制文本/保存图片；
   死法图鉴、假排片榜、反话文案（F9）。
5. **圈层梗分层**（F8）+ 敏感线含蓄化（用户点名内容）。

## 2. 最终选题

**《杀青》—— 人生短剧模拟器。**
一句话：你过的不叫日子，叫片场；你活的不叫人生，叫剧本；死了不叫死，叫杀青。
游戏打分打的是这部"人生短剧"好不好看——不是你过得好不好，也不是你过得有多惨
（平顺是烂片，纯摆烂是烂片，大起大落有伏笔回收的荒诞戏才是爆款）。

## 3. 验证：用户点名的每一条要求是否有证据支撑

| 要求 | 调研依据 |
|---|---|
| 玩法只需简单点击 | 人生重开零决策验证（2亿访问）；F3/X3 |
| 亚文化圈层+圈层梗 | F8；原作玩梗事件是裂变燃料 |
| 隐秘轨道（修仙/电竞/偶像/…） | 修仙教训 F5：隐藏内容=留存引擎 |
| 打分打"故事好不好看" | F4 作品型传播；苏丹"机制即叙事" |

| 暗黑亚文化（od/地雷）含蓄 | 短剧"情绪密度"可借，红线另立（03-subculture §3） |
| 传播爆炸 | F1-F10 全部 |
