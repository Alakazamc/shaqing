# 圈层 × 梗雷达（词库顶层设计）

> 用户约束：圈子内部梗和新梗为主，避免老人味（内卷/躺平/ yyds 等已官媒化/过气的不得作主料）。
> 本文档定义圈层清单、各圈层词汇样例、与轨道的映射、时效分层和内容红线。
> 正式词库在 `content/lexicon.js`，本文是词库的"地质图"。

## 1. 时效分层

| 层 | 定义 | 处理方式 |
|---|---|---|
| L1 沉淀层 | 已进入汉语日常，2-3 年内不过期：社死、破防、已读乱回、嘴替、精神状态领先、含金量、职场黑话（拉通/对齐/赋能）、上岸、搭子 | 可直接织入事件主干 |
| L2 圈层层 | 圈内高频、圈外需上下文：吃谷/吧唧/痛包、空军（钓鱼）、天胡开局、歪了/小保底、提桶跑路、挂逼水、momo | 绑定轨道/圈层事件，圈内人截图转发的核心燃料 |
| L3 冒险层 | 近 12 个月新梗，可能过期：以发版时热榜校准 | 只进 lexicon 替换槽，不进事件主干 |

## 3. 敏感圈层的处理原则（用户点名 + 红线）

用户明确要求纳入：**地雷系、跨性别、药物过量（含蓄表达）**。处理原则：

1. **地雷系/emo 亚文化**：词汇（地雷系、量产型、黑白粉、蓄电）可出现，
   事件呈现"情绪波动与自我拉扯"，收尾必须落在"有人拉了一把/自己缓过来了/继续活着"，
   不呈现行为细节，不渲染美感。
2. **药物/OD**：只允许含蓄暗示级文本（"朋友递来一颗不知名的糖""那晚之后你什么都不记得了""你再也没有醒来"）。
   禁止：任何真实药物名、方法、剂量、"舒服"向描写。死亡结算文案克制。
3. **跨性别**：人物不是笑点，梗不猎奇。事件方向是身份认同与周围世界的摩擦与和解
   （"你在网上认识了和你一样的姐妹""镜子里的你终于顺眼了"）。
   允许幽默，幽默的对象永远是环境不是人。
4. **所有敏感线的共同原则**：可以"死得荒诞"，不可以"死得指导"；可以"活得离谱"，
   不可以"活得教唆"。涉及人群的笑话，靶子是结构与环境，不是具体的人和身份。

## 4. 梗注入工程

- `lexicon.js` 按圈层组织词条：`{id, circle, text, tier, aliases[]}`。
- 事件文本用占位符 `{lex:bookish}` 引用；生成时按玩家当前轨道/圈层亲和度选词。
- 每季度热榜校准一次 L3 词条（文档记录校准日期），过期词条替换不改事件。
