# UGC 事件扩池规范（社区共创指南）

> 原作《人生重开模拟器》验证过的路线：开源 + 社区 PR 扩事件池。
> 本文档是给贡献者（以及未来的自己）的写作合同。所有 PR 必须通过
> `node test/validate.mjs` 与 `node test/simulate.mjs 300`。

## 1. 加一条事件的最小流程

1. 选对文件：按年龄段放（`content/events-child.js` 0-12 / `-teen` 13-18 /
   `-young` 19-28 / `-mid` 29-45 / `-late` 46-90 / `-rare` 稀有传说 / `-more*` 综合）。
2. 追加到文件末尾的 `BH.EVENTS.push(...)` 里，沿用 schema：

```js
{ id: 'y201',            // 前缀+流水号；全局唯一（validate 会查重）
  a: [19, 24],           // 年龄区间 [min, max]
  g: 1,                  // 稀有度：0普通 / 1稀有 / 2史诗 / 3传说
  t: '你……',             // 一行文本，主语"你"，15-40 字最佳
  e: { JOY: 1 },         // 五维效果 CHR/INT/STR/MNY/JOY，可选；另支持 LIF
  tags: ['chaos'],       // 语义标签（影响片名/弹幕/反讽），可选
  flag: 'my_flag',       // 写入旗标，供后续事件 inc:{f:[...]} 引用，可选
  br: [                  // 分支选项（2-3 个），可选
    { t: '选项名', rt: '结果叙述', e: { MNY: 1 }, tg: ['rich'], f: 'took_deal' },
  ],
}
```

3. 跑 `node test/validate.mjs`——红灯全灭才能提交。

## 2. 写作守则（什么能进池）

**必须**：主语是"你"；一行一个画面；结尾有落点（笑点/反差/余味任占其一）。
**优先**：具体名词（"三斤小龙虾"）> 抽象形容（"很美味"）；圈层黑话走 L1/L2 层。
**克制**：传说级（g3）是稀缺资源，标准是"值得截图"；单 PR 里 g3 不超过 2 条。

### 红线（validate 自动扫描，命中即拒）

- 真实人名、平台/品牌名（写"某短视频平台"或干脆不写）
- 药物/自我伤害的方法、剂量、美化描写；emo 线的出口必须存在
- 笑话的靶子永远是环境和结构，不是具体人群和身份

### 语感基准（对照现有文案找调）

好的：`你把压岁钱偷偷买了游戏机，藏在数学书下面，并存活了整整一学期。`
不好的：`你的童年非常有趣，发生了很多事情。`

## 3. 轨道扩池

新轨道 = `content/tracks2.js` 格式：entry（机缘形态入口文本）+ cond（触发条件函数）
+ 6 条阶段事件（`tr:{id,d}` 深度 2-6，深处用 `inc:{trd:[[id,n]]}` 门槛）
+ endingGood/endingBad（独占结局称号，cond 按 d>=6 / d>=3）。
同时补：片名池（`engine.js makeTitle mains`）、海报线名（`poster.js tname`）、弹幕池（`misc.js`）。
入口 cond 必须性别中性（正典 §2.4 红线）。

## 4. 数字与平衡

- grade 金字塔目标：普通 ~55% / 稀有 ~28% / 史诗 ~13% / 传说 ~4%
- 每个年龄段可用事件 ≥3 条（validate 会警告），补缺口优先
- 改动效果数值后跑 `node test/simulate.mjs 500`，对照 README 里的验收基线
  （评分均值 ~6-7 / 最高 9.9，票房均值 ~40 亿，决策 ~20 次/局）

## 5. PR 检查单

- [ ] `node test/validate.mjs` 0 错误
- [ ] `node test/simulate.mjs 300` 零失败、指标未漂移
- [ ] 新文案自读三遍：有没有老人味？有没有说教？靶子对不对？
- [ ] id 前缀符合文件分区且不与现有冲突
- [ ] 涉及敏感圈层的，对照 `docs/research/03-subculture.md` §3 四原则自查
