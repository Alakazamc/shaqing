## 0. 状态模型

一局的全部状态。除此之外任何模块不得新增顶层状态字段。

### 0.1 五维基础属性（沿用原作命名，玩家零学习成本）

| 键 | 名 | 范围 | 说明 |
|---|---|---|---|
| `CHR` | 颜 | -5 … 20 | |
| `INT` | 智 | -5 … 20 | |
| `STR` | 体 | -5 … 20 | 归零即触发死亡事件池 |
| `MNY` | 钱 | -5 … 20 | **是水位等级不是货币**，按档位显示（负债/温饱/小康/新贵/离谱） |
| `SPR` | 心 | -5 … 20 | |

**五维起始值均为 3**，再由开局四项（家庭 / 性别 / 性格 / 天赋）加减。

> 起始值必须 > 0，因为 `modules/05-chapter.md` §5 把 `STR ≤ 0` 定为死亡条件；
> 起始 0 会导致出生即死。取 3 而不是 5，是为了让"正常人生落在 0–10"这句话
> 里的下半区留出空间——开局就在中位数会让所有下降都显得无关痛痒。
> 这个缺陷是在跑第一局完整流程时发现的。

正常人生落在 0–10；超过 10 属于离谱区间（暴富、修仙、爆红），显示时给特殊配色。
沿用"等级而非货币"是从原作学的：`MNY` 判档呈现，避免玩家去算钱。

### 0.2 本作特有的三个轴

| 键 | 名 | 范围 | 起始 | 作用 |
|---|---|---|---|---|
| `AUD` | 观众 | 1 … 100 | **3** | 收视放大系数的来源。起始值极低＝"只有家里人在看" |
| `HOOK` | 戏瘾 | 0 … 20 | 0 | 对表演的沉迷度。加码 `+1…+3`，收手 `-2…-4` |
| `HOOKP` | 戏瘾峰值 | 0 … 20 | 0 | 只增不减，记录本局最高 `HOOK` |

`AUD` 是全局最重要的设计杠杆：它让"童年期把自己搞得很惨"在数学上不值钱
（没有观众看），从根上堵掉 BRIEF C2 担心的"摆烂最优解"。
`HOOK` / `HOOKP` 是真结局（C7）唯一的判定依据，见 `modules/08-true-ending.md`。

### 0.5 NPC

## 1. 循环：脉冲、季、决策点

### 1.1 脉冲（pulse）

**一次点击 = 一个脉冲。** 脉冲分两种，二者都只需要点击（满足 C1）：

- **决策脉冲** — 弹出 2–3 个选项，玩家点一个。选择即构筑（BRIEF §3：选项就是商店）。
- **推进脉冲** — 点「继续」。若接下来若干年无事件，**一次推进压缩 1–3 年**，
  掠过的年份以一行淡出小字呈现（`11 岁 · 没什么事发生`）。

压缩是时长控制的关键：不压缩的话 0–70 岁要点 70 次，太长。

### 1.2 一局时长目标 `[Q6]`

| 指标 | 目标值 |
|---|---|
| 首局时长 | 5–7 分钟 |
| 熟练局时长 | **150–190 秒**（脉冲上调后同步放宽） |
| 总脉冲数 | **45–60**（实测中位数 54–57） |
| 其中决策脉冲 | **12–14** |
| **其中场景** | **3–4**（见 `modules/16-scenes.md`） |
| 单个决策选项数 | 2–3（硬上限 3） |
| 单条事件文案 | ≤ 60 字（手机竖屏一屏内读完） |
| 单个场景节拍文案 | ≤ 30 字 |

> **修订说明**：本表初版为"总脉冲 30–45 / 决策 14–16 / 熟练局 100–150 秒"。
> 引入场景模式后，3–4 个决策点各展开为 3–6 个节拍，脉冲数必然上升。
> 修正方式是**用更少但更深的决策换掉更多但更浅的决策**
> （决策点 14–16 → 12–14），而不是单纯接受时长变长。
> 详细推算见 `modules/16-scenes.md` §3。

熟练局中位数**超过 170 秒即视为不达标**，
优先削减非场景决策点，而不是削减场景——
场景是深度的来源，浅决策不是。

C6 的要求是"看完一条截图就想自己开一局"，
所以时长上限是硬的：接近 3 分钟就已经在损耗传播链。

### 1.3 季（章节）

一条命 = 一部剧的 5 季。年龄区间与决策点密度：

| 季 | 名 | 年龄 | 决策点 | 其中场景 | 续订阈值 | 备注 |
|---|---|---|---|---|---|---|
| S1 | 试镜 | 0–11 | 2 | 0 | **无** | 不会腰斩。`AUD` 极低，此期数值不值钱 |
| S2 | 出道 | 12–17 | 2 | 0–1 | 90 | 第一次可能被腰斩 |
| S3 | 当红 | 18–29 | 4 | 1–2 | 700 | 主构筑成型期，隐秘轨道主要入口 |
| S4 | 中年 | 30–49 | 3 | 1–2 | 30000 | 倍率兑现期 |
| S5 | 收尾 | 50–70 | 2 | 0–1 | **无** | 终局与死法，反讽乘数在此结算 |

决策点合计 13（区间 12–14），其中场景 3–4。
**S4 必须至少有一个场景，且应为加码/收手场景**——
它是真结局条件 ④（至少一次高价收手在 S4 或更晚）的承载点，
理由见 `modules/16-scenes.md` §6。

> 阈值为**待实测调参值**，见 §7。纵切片跑通后按实际分布回填。

S1 不设阈值是刻意的：开局就被腰斩会毁掉"再来一局"的冲动，
而 `AUD` 已经让 S1 的数值天然不值钱，不需要再用失败惩罚。

**同理，S1 也不触发死亡。** `modules/05-chapter.md` §5 的 `STR ≤ 0` 死亡条件
在试镜期内不生效——否则童年期的属性消耗会造成"六岁因为挑水累死"这类荒谬结局。
这条与"S1 不腰斩"是同一个原则：试镜期不淘汰。

### 1.35 完整度是硬要求：不用死亡当惩罚

**每一局都必须播满五季。** 惩罚只能压低分数、累积污点，
**绝不能截断这一局**。

理由有三条，第三条最硬：

1. 走不到 S5，反讽乘数（上限 4.0，全局最大单一杠杆）就永远用不上
2. 振幅需要完整弧线，中途截断的人生做不出大起大落
3. **`C6` 要求每局产出一件可截图的作品。** 一条被属性耗尽掐断的人生
   不是故事，只是残缺——它没有收尾、没有死法、没有反讽，
   结算页拿不出手

因此以下两种"提前结束"全部废除：

| 旧设计 | 新设计 |
|---|---|
| `STR ≤ 0` → 立即死亡 | → **垮掉**：`STR` 钳在 1，得污点，磨损减半，继续演 |
| 第 2 次腰斩 → 提前完结 | → 继续注水续命，`烂尾` 标签当场挂上，但**剧照播到 S5** |

**惩罚形态统一为：污点 + 观众下降 + 阈值抬高。**
这三样都压低最终评分，但都不剥夺"看完自己这条命"。

这同时更符合 `C3`：污点在吃污点的构筑下是燃料，
所以"垮掉"与"烂尾"都能被玩成优势。而截断式死亡没法被玩成优势——它只是终止。

### 1.4 人生长度由构筑决定 `[Q2]`

**基础续订上限 70 岁，但它是上限不是终点。**

- **加更** — 某季收视 ≥ 阈值 ×2，该季追加 2–4 年（更多脉冲＝更多分）。
- **人设改上限** — 例：`醉生梦死` 上限 −20 且每年倍率 +；
  `筑基` 上限 +30 并解锁隐藏第六季「化神」。人设牌的 `lifespan` 在被事件授予时立即生效。
- **延寿型事件线** — 魔法与科幻线的主链/分叉终点可以授予带 `lifespan` 的人设牌；寿命增加必须伴随倍率、属性、曝光或收视代价，不能成为无条件奖励。
- **死亡是内容驱动的**，不是属性耗尽。只有两种触发：
  到达寿命上限时抽死法事件池，或某个事件本身就是死亡（刻意设计的高潮）。
  `STR ≤ 0` **不再致死**，改为「垮掉」（见 §1.35）。

所以"活多久"是构筑结果，且短命构筑不是劣势——它把分数压缩进更少年份，倍率更极端。

## 2. 年度收视：唯一的计分公式

每个脉冲结算一次。这是玩家看到数字跳动、连锁、爆炸的地方。

```
B = 事件桥段基数 + 选项桥段 + Σ(人设 addDrama)
M = (1 + Σ(人设 addMult)) × Π(人设 xMult)
A = AUD / 10
F = 0.6 ^ (该 trope 本局已计次数)

R_year = round( B × M × A × F )
```

四个因子各自承担一个设计职责，缺一不可：

| 因子 | 职责 | 取值参考 |
|---|---|---|
| `B` 桥段 | 内容产出的基础分（＝小丑牌的 chips） | 事件基数 3–30；选项 0–40（加码选项取高值） |
| `M` 倍率 | 构筑连锁（＝小丑牌的 mult） | `addMult` 0.2–1.5；`xMult` 1.5–3.0（稀有） |
| `A` 观众 | 时序权重。起始 0.3，巅峰可达 7+ | 由 `AUD` 决定 |
| `F` 疲劳 | **反刷分**：观众看腻了 | 第 1 次 1.0，第 2 次 0.6，第 3 次 0.36 |

`addMult` 用加法、`xMult` 用乘法且限定稀有，是从小丑牌学的控制手段：
保证数字能爆炸，但爆炸的上界仍然可预测。

季收视 `S_season = Σ R_year`（含该季加更年份）。

### 2.1 `AUD` 如何增长

`AUD` 只由**事件与选项显式给予**，不由公式自动推导（便于内容层精确控制节奏）：

- 出圈类事件 `+3 … +15`
- 塌房、销声匿迹类 `−5 … −20`
- 腰斩后注水续命 `AUD` 直接砍半

这条让"观众"成为内容作者手里的旋钮，而不是一个失控的复利变量。

## 3. 终局三乘数与评分

```
总收视 = (Σ S_season) × Amp × Com × Iro
```

三乘数直接对应 BRIEF C2 的振幅 / 贯彻 / 反讽。

### 3.1 振幅 `Amp` ∈ [0.5, 4.0] `[Q3]`

BRIEF 点名的难题：**如何量化才不被"先自残再暴富"的固定套路刷爆。**

先定义逐年**水位**（记入 `WLOG`）：

```
W = clamp( 6×norm(MNY) + 3×社会位置 + 2×norm(SPR), 1, 100 )
```
（`社会位置` 由轨道深度与旗标决定，见 `modules/04-tracks.md`。归一到 1 起步是为了 log 可取。）

把 `WLOG` 按一阶差分的符号变化切成单调段 `seg₁…segₙ`，每段幅度 `aᵢ = |log₁₀(W_end / W_start)|`：

```
Amp_raw = Σᵢ min(aᵢ, 0.8) × gᵢ × rᵢ        (n ≥ 2，否则 Amp_raw = 0)
Amp     = clamp(0.5 + Amp_raw, 0.5, 4.0)
```

**四道反刷分闸门**，每道各堵一种套路：

| 闸门 | 定义 | 堵的是 |
|---|---|---|
| 段幅上限 | `min(aᵢ, 0.8)` | 把单次跳变拉到极端来刷分 |
| 观众权重 `gᵢ` | `min(该段平均 AUD / 20, 1.5)` | **童年期自残**——没观众看，几乎不计分 |
| 套路重复 `rᵢ` | 该段 (起点 trope, 终点 trope) 组合此前出现过 → `0.5` | "自残→暴富"重复第二遍 |
| 必须多段 | `n < 2` 时归零 | 一路平顺、一路烂到底（两者都是单调曲线） |

加上 §2 的 `F` 疲劳系数，全局共**五处**反刷分机制。
"观众权重"这一道是最关键的：它让最容易被 min-max 的人生前段天然廉价。

### 3.2 贯彻 `Com` ∈ [0.5, 3.0]

```
p   = 主导轨道决策数 / 总决策数
d   = 主导轨道深度 / 该轨道最大深度
Com = clamp(0.5 + 2.5 × p^1.5 × d, 0.5, 3.0)
```

**"什么都试了一下"硬惩罚**：若涉及 ≥3 条轨道且全部 `depth ≤ 2`，`Com` 强制为 `0.5`。
`p` 取 1.5 次幂是为了让"半途而废的修仙者"明显劣于"走火入魔的修仙者"（BRIEF C2 原话）。

### 3.3 反讽 `Iro` ∈ {1.0, 1.5, 2.5, 4.0}

取死法事件的 `tags` 与 `(开局天赋 tags ∪ 首张人设 tags ∪ S1 事件 tags)` 求交集：

| 命中数 | `Iro` |
|---|---|
| 0 | 1.0 |
| 1 | 1.5 |
| 2 | 2.5 |
| ≥3 | 4.0 |

额外：死法 trope 与本局**最高收视年**的 trope 相同 → `Iro += 0.5`（首尾呼应）。

### 3.4 评分映射（豆瓣式）

```
评分 = clamp( 2.0 + 1.5 × log₁₀(总收视 / 2000), 1.0, 9.9 )
```

| 总收视 | 评分 |
|---|---|
| 2 000 | 2.0 |
| 20 000 | 3.5 |
| 200 000 | 5.0 |
| 2 000 000 | 6.5 |
| 20 000 000 | 8.0 |

> **修订记录**：pivot 初版取 2000，首轮内容量较小时总收视中位数约 2 300，
> 当时的分布被误读为需要降低 pivot。随着职业、事件线和异常内容接入，
> 当前实测 random 1000 局总收视中位数约 2.6 万；若继续用 250，
> 普通局会整体抬到 5 分以上。现回填为 **2000**：random 评分回到 3–4 分默认区间，
> greedy 仍明显高于 random 但低于 7.5 上限。公式结构未改，只修正量级系数。

**低分是笑点，收视数字是炫耀点。** 两个数都要在结算页显示：
豆瓣式低分负责"笑死，我的人生 3.1 分"的转发，原始收视量级负责小丑牌式的构筑炫耀。
默认玩家落在 3–5 分区间，8 分以上需要成型构筑，这是刻意的。

真结局例外：不给评分，位置显示 `—`（C7）。

## 4. 季末结算：续订 / 加更 / 腰斩 `[Q1]`

BRIEF §4 的问题：不达标是直接死亡，还是转入更荒诞的低分支？
**答案是后者，且它必须是个笑点。**

季末比较 `S_season` 与阈值 `T_season`：

| 结果 | 条件 | 处理 |
|---|---|---|
| **加更** | `S ≥ 2×T` | 本季追加 2–4 年，播一段"制作方追加投资"的文本 |
| **续订** | `S ≥ T` | 正常进入下一季 |
| **腰斩** | `S < T` | 进入注水续命分支（见下） |

### 4.1 腰斩与注水续命

腰斩不是死亡，是**烂剧的续命手段**：游戏用离谱方式强行续订——
穿越、失忆、失散多年的双胞胎、"其实那是一场梦"。这本身好笑且可截图。

代价：

- 获得污点牌 **`注水`**（永不移除，可叠加，每张令全局 `M × 0.85`）
- `AUD` 砍半
- 下一季阈值 `× 1.5`
- 累计**第 2 次**腰斩 → 挂上 `烂尾` 标签，继续注水续命并播到 S5；不提前截断。

### 4.2 这条机制如何满足 C3

BRIEF C3 的审查标准是：一条机制若不能让"堕落/失败/荒诞"在某种构筑下变成数值优势，它就不够本作。

`注水` 是污点牌，因此天赋 `反社会人格`（每张污点 `+1` 倍率）等吃污点的构筑下，
**被腰斩反而是构筑燃料**——玩家会主动去把某一季搞垮。
计分公式于是自己否定了自己设定的失败条件，态度不靠旁白表达。

## 5. 隐秘轨道的可发现性 `[Q4]`

BRIEF §4 的问题：入口如何既隐蔽、又不至于让玩家永远发现不了。四条规则同时成立：

1. **文本层永不打标签。** 入口选项读起来必须像普通选项
   （`跟着那个老头去后山` 而不是 `【修仙】拜师`）。不给图标、不给稀有度描边。
2. **门槛是状态，不是低概率随机。** 入口出现取决于属性/污点/人设/旗标组合。
   因此可攻略、可复现、可用 seed 分享——这同时服务 C6。
3. **每局保底暴露一条。** 每局至少有 1 条隐秘轨道的入口会出现在选项里（具体哪条由 seed 决定）。
   玩家不一定会点，但一定会看见。
4. **图鉴显示未知计数。** `已发现 6 / 23` 加一排 `???`，明确告诉玩家还有多少没找到。
   **例外：真结局的槽位完全空白，不计入分母**（C7 要求游戏从不暗示它存在）。

第 2 条是与原作的关键差异。原作事件是纯加权随机抽取
（`life.js` 的 `random(events)`，玩家全程零决策），
本作把随机让位给状态门槛，因为"我怎么触发的"必须可被讲述，否则玩家无法在截图里炫耀。

## 6. meta 进度解锁什么 `[Q5]`

结算按总收视产出货币 **`素材`**，并在结算页之后进行**一次抽卡**
（详见 `modules/12-gacha.md`）。可解锁的东西**只有六类**：

| 类别 | 内容 |
|---|---|
| 人设牌进池 | 让某张牌**有机会出现**，不是直接发给玩家 |
| 开局天赋池扩容 | 保留原作的天赋三选一 |
| 家庭 / 性格项 | 开局四项的选项，分 T1–T3 |
| NPC 进池 | 让某个 NPC 有机会在后续局出场 |
| 轨道起点权限 | 解锁某条隐秘轨道的入口资格 |
| 图鉴与统计 | 轨道图鉴、结局图鉴、人设收集 |

解锁走**双轨**：抽卡是快车道，素材定向解锁是保证到货的慢车道。

**"高级"的定义是更离谱，不是更强**：T3 内容触发更极端的事件链，
但因为起点已经离谱，反差空间被压缩，反而更难做出高振幅
（推导见 `modules/11-origin.md` §7）。

**明确不解锁任何数值强化。** 没有练度碾压，每局在同一套公式下是公平的——
否则新玩家的截图和老玩家的截图不可比，C6 的传播链会断。

长期目标是图鉴收集，因为它直接服务传播：
`我发现了 23 条轨道里的 17 条` 本身就是一句转发文案。

A 期运行时的素材来源已经落地：总收视对数换算（最低 5）+
首次发现轨道 20 + 首次达成结局 15 + 经历过腰斩 5；重复抽卡按条目的
`dupValue` 另行补入。结算页显示本局素材来源，抽卡页显示评分对档位权重、
路线/NPC 对主题池的影响。`save.unlocked` 已保存抽卡结果；按解锁状态过滤
开局池和事件池属于后续元进度阶段，不能把“写入记录”误称为“已改变池子”。

## 7. 真结局在系统层的位置（C7）

真结局**不是一个高分结局，是一次退出计分**。系统层只需要保证三件事：

1. `HOOK` / `HOOKP` 两个轴存在且被所有加码/收手选项正确读写。
2. 选项数据结构必须能标记 `escalate`（加码）与 `restraint`（收手），
   且收手时 **UI 必须显示放弃掉的具体分数**——代价不可见就不成立。
3. 结算页支持"无评分"形态。

判定条件、文本基调与反滥用规则见 `modules/08-true-ending.md`。

## 8. 调参与平衡回填（2026-08-02）

纵切片现已可批量运行。以下结果使用固定 seed 前缀 `TUNE00`，因此命令可重复；
`--seed` 后的每一局使用 `TUNE00 + i`。本节只调整量级系数与季阈值，没有改变公式结构。

### 8.1 可复现命令

```text
node test/tune.mjs --runs 1000 --strategy random --seed TUNE00
node test/tune.mjs --runs 200  --strategy greedy --seed TUNE00
node test/browser-check.mjs
```

调参脚本现在同时输出：评分/总收视/三乘数/腰斩/真结局、性别中位数差、
五维 effect 关联收视、事件线贡献、脉冲和时长预算。T-contribution 的定义是：
某次选择的 `effect` 触及该属性时，把该脉冲的收视记入该属性；它是可见性统计，
不是声称年度公式只由该属性产生。

### 8.2 核心结果

| 指标 | random（1000 局） | greedy（200 局） | 目标/结论 |
|---|---:|---:|---|
| 评分中位数 | 3.6 | 5.0 | random 3.0–4.0；greedy ≤7.5，均通过 |
| 总收视中位数 | 24,791 | 189,576 | greedy 明显高于 random |
| 总脉冲中位数 | 57 | 59 | SYSTEM 45–60，均在区间内 |
| 腰斩率 | 76.6% | 6.5% | greedy >0，通过；random 偏高，保留为失败具有代价的设计信号 |
| 真结局率 | 1.3% | 0.0% | random 为稀有命中，未形成可稳定刷出的路线 |
| 死亡年龄中位数 | 79 | 83 | 五季完整度保持 |
| 三乘数均值 Amp / Com / Iro | 1.01 / 0.69 / 1.42 | 1.17 / 0.65 / 1.39 | 结构均有贡献 |

季阈值最终回填为 **S2=90、S3=700、S4=30000**。S4 从 4000 上调，
是为了让 greedy 在 200 局中出现 13 次腰斩而不是 0 次；S2/S3 保持当前可达性，
S1/S5 无阈值。随机局腰斩偏高，说明普通点选仍会经常产生低分/注水故事，
而不是无脑通关；后续内容扩充时再按事件量复测，不通过提高倍率掩盖它。

评分 pivot 最终回填为 **2000**。当前内容量下 pivot=250 会把 random 中位数抬到 5 分以上，
与“默认局 3–4 分、成型构筑才高分”的目标冲突。

### 8.3 平衡检查结果

**T-gender（random 1000 局）：** `sex_nan` n=317 / 中位数 3.6，
`sex_nv` n=312 / 3.8，`sex_wei` n=371 / 3.5；组间极差 **0.30**，满足 ≤0.3。

**T-contribution（random，每局平均关联收视）：**

| 性别 | CHR | INT | STR | MNY | SPR |
|---|---:|---:|---:|---:|---:|
| sex_nan | 1454.0 | 816.3 | 2976.9 | 9620.7 | 20513.7 |
| sex_nv | 1970.6 | 841.9 | 2732.2 | 11483.1 | 25496.9 |
| sex_wei | 1480.8 | 726.8 | 2477.7 | 9803.2 | 21712.7 |

**T-eventline（random）：** 普通非事件线脉冲基线为 1591.6；事件线按命中局的
单局均值 / 单脉冲均值分别为：`el_dilei` 1948.5 / 665.9（279 局）、
`el_pingtai` 5669.3 / 2838.7（836 局）、`el_qishou` 456.9 / 157.3（320 局）、
`el_wangyou` 1305.3 / 461.0（530 局）、`el_xiuxian` 2079.7 / 710.6（191 局）。

总脉冲符合更新后的 45–60 区间。当前首发内容实际只有平台加码 1 个可触发场景，
场景中位数为 1，尚未达到设计目标的每局 3–4 个场景；这是内容量/B 期缺口，
不能用调整压缩倍率伪装成通过。`MAX_SCENES_PER_RUN=4` 的引擎上限与 A63 仍已通过。
