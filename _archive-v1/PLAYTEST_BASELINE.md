## 2. 当前可玩循环

```text
BOOT
  → ORIGIN（家庭 / 性别 / 性格，可重抽）
  → TALENT（三选一，受元进度影响的 archive slot）
  → YEAR
       ├─ 可规划时显示路线 offers，选择 plan 后写入 ROUTE / DECK
       ├─ LOOP：同年龄事件逐项消耗，直到出口或强制破环
       ├─ SCENE：事件线逐拍展开，最后只结算一次年度收视
       ├─ pending：事件显示后选择 2–3 个选项并应用后果
       └─ 无事件年份可压缩，进入下一年龄或季末
  SEASON_END
       ├─ extend / renew：季末奖励 → REWARD → 下一季
       └─ cancel：注水、AUD 砍半 → REVIVE → 继续完整五季
  ENDING → SETTLEMENT（死法、三乘数、评分、timeline）
           → GACHA / ARCHIVE / seed 反馈 → 再来一局
```

一局仍必须播满五季；垮掉、腰斩和污点会压低结果，但不会用属性耗尽截断故事。S1 不进入腰斩线，S2–S4 按季收视续订、加更或腰斩，S5 负责收尾和结算。

## 3. 玩家可见的信息层

运行页当前展示：年龄、季别、寿命、年度收视、AUD、HOOK、属性水位、职业、关系摘要、当前路线风险、路线可能内容、DECK 节目牌、路线锁定状态、操作提示和 LIFE FEED。

选择和结算后的已有结果会被投影为轻量反馈：收视入账/爆发、构筑合拍、路线锁定、隐藏轨道、关系变化、加更/续订/腰斩、奖励类型和最终评分。反馈不新增状态字段、货币、倍率或引擎分支。

结算页展示 RUN LOG、季收视、三乘数、评分、结局和可截图信息；ARCHIVE 保持单页 phase 浏览，只显示已发现的事件、事件线、计划和结局，不提前泄露未发现真结局或隐藏条件。

本轮没有发现任务 #8 HUD/ARCHIVE 或任务 #9 feedback 引入的行为回归：随机 CONTENT06 的评分 3.9、总收视 36,145、脉冲 69、腰斩 61%、真结局 0% 与任务 #7 末次基线一致；新增检查只投影已有结果。

当前应保留的平衡债务：减少非场景决策和无意义推进以压低总脉冲/时长；让可达事件线在一局中更稳定地承载 3–4 个场景；复盘 random 与 greedy 的 S4 腰斩差异，确认风险提示是否足够可读。暂不通过提高年度倍率或改变终局公式处理这些告警。

真结局在 random/greedy 自动策略下均为 0% 不等于不可达；核心 A19–A23 与定向契约已验证其条件、不可误触发和 `rating=null` 语义。是否能被玩家理解并主动达成，留到任务 #11 的高分/异常/真结局试玩。
