# 模块：计分（收视率）

> 上位：`docs/SYSTEM.md` §2 §3。本文只做展开与数值细化，**不新立公式**。
> 若本文与 SYSTEM 冲突，以 SYSTEM 为准。

## 1. 为什么是"收视率"而不是"人生评价"

这个隐喻不是包装，它一次性解掉四个设计难题：

| 难题 | 收视率框架给出的答案 |
|---|---|
| 为什么摆烂不得分（C2） | 无聊的惨同样没人看。与道德无关，观众不买单而已 |
| 反刷分规则的合理性 | 重复的戏码不值钱——观众看腻了。规则自带叙事解释 |
| 失败如何不干瘪 | 季末不达标＝**腰斩**。游戏把你的人生当烂剧砍掉，本身是笑点 |
| 分享卡长什么样 | 豆瓣式条目页。中文互联网不需要教就懂这张图 |

而且它把解构做进了数学（C3）：**把人生的价值直接定义成对观众的娱乐价值**，
比任何嘲讽台词都狠，且全程不需要旁白开口。

## 2. 年度脉冲结算顺序

顺序是有意义的，实现必须严格按此执行：

```
1. 应用选项 effect（属性、AUD、HOOK 增减）
2. 授予 grant（人设牌 / 污点牌 / 旗标 / 轨道深度）
3. 收集 B：事件桥段基数 + 选项桥段 + Σ人设 addDrama
4. 收集 M：(1 + Σ addMult) × Π xMult      ← 污点惩罚也在此参与
5. 查 trope 计数得 F，然后把本次 trope 计数 +1
6. A = AUD / 10       ← 用的是本次 effect 之后的 AUD
7. R_year = round(B × M × A × F)
8. 记录水位 W 到 WLOG，累加 S_season
```

第 5 步的顺序很关键：**本次结算用的是"之前"的计数**，
所以同一 trope 第一次出现时 `F = 1.0`，不会自己打折自己。

## 3. 数值区间

### 3.1 桥段分 `B` 的来源

| 来源 | 区间 | 说明 |
|---|---|---|
| 事件基数 | 3 – 30 | 日常事件 3–8；转折事件 12–20；奇观事件 20–30 |
| 选项桥段 | 0 – 40 | **加码选项取高值**，收手选项通常为 0 |
| 人设 `addDrama` | 1 – 12 每张 | 条件式，如"每张污点牌 +2" |

### 3.2 倍率 `M` 的来源

| 来源 | 区间 | 稀有度 |
|---|---|---|
| `addMult` | +0.2 – +1.5 | 普通 / 稀有 |
| `xMult` | ×1.5 – ×3.0 | 仅史诗及以上 |
| 污点 `注水` | ×0.85 每张 | 惩罚，可叠 |

`addMult` 加法、`xMult` 乘法且限稀有，是从小丑牌学来的控制手段：
数字能爆炸，但上界仍可预测。设计审查规则：
**任何单张牌都不得让 `M` 超过 4.0；`M > 8` 必须是至少 3 张牌咬合的结果。**

### 3.3 一个算例（青年期，成型中的构筑）

```
事件「直播时说错话」基数 18
选项「加码，把话说得更绝」桥段 +25
人设【抽象怪】addDrama +6            → B = 49
人设【抽象怪】addMult +0.8
人设【大冤种】addMult +0.5
人设【破防现场】xMult ×2.0           → M = (1 + 1.3) × 2.0 = 4.6
AUD = 38                              → A = 3.8
trope「翻车」本局第 2 次              → F = 0.6

R_year = round(49 × 4.6 × 3.8 × 0.6) = 514
```

同一年若 `F = 1.0`（首次翻车）则为 857。**疲劳惩罚玩家看得见**，
UI 必须显示 `×0.6 观众看腻了`，否则反刷分机制变成暗箱。

## 4. 振幅 `Amp` 的实现细则

SYSTEM §3.1 给了公式，这里定实现口径。

### 4.1 水位 `W`

```
norm(x) = clamp((x + 5) / 25, 0, 1)     // 属性域 -5…20 映射到 0…1
w       = 0.5×norm(MNY) + 0.3×(社会位置/10) + 0.2×norm(SPR)   // → [0, 1]
W       = 1 + 99×w                                            // → [1, 100]
```
`社会位置` ∈ [0, 10]，由轨道深度与旗标决定，见 `04-tracks.md`。

> **修订记录**：初版写作 `W = clamp(6×norm(MNY) + 3×社会位置 + 2×norm(SPR), 1, 100)`。
> 代入极值可得上界仅 38，`W` 永远填不满 `[1, 100]`，
> 且与 `11-origin.md` §7 用到的 `W ≈ 60` 不自洽（该值在旧公式下不可达）。
> 改为先把三项加权归一到 `[0, 1]` 再映射到 `[1, 100]`，
> 保持权重比例 5 : 3 : 2 不变。这个缺陷是在实现 `state.js` 时代入数字发现的。

`W` 每年记一次（含压缩掠过的年份，用当年年末状态）。

### 4.2 分段

按 `WLOG` 一阶差分的**符号**切段，忽略差分为 0 的年份（平年不打断单调段）：

```
diffs = WLOG[i+1] - WLOG[i]，丢弃 0
段边界 = 符号发生变化的位置
```

段数 `n < 2` → `Amp_raw = 0`（单调曲线，无论向上还是向下）。
这一条同时否掉"一路平顺"和"一路烂到底"，是 C2 的直接实现。

### 4.3 每段的三个系数

| 系数 | 公式 | 取值 |
|---|---|---|
| 幅度 | `aᵢ = |log₁₀(W_end / W_start)|`，取 `min(aᵢ, 0.8)` | ≤ 0.8 |
| 观众权重 | `gᵢ = min(段内平均 AUD / 20, 1.5)` | 0.05 – 1.5 |
| 套路重复 | `rᵢ = 0.5` 若 (起点 trope, 终点 trope) 组合此前出现过，否则 `1.0` | 0.5 / 1.0 |

```
Amp = clamp(0.5 + Σᵢ min(aᵢ, 0.8) × gᵢ × rᵢ, 0.5, 4.0)
```

### 4.4 四道闸门各自堵什么

| 套路 | 被哪道闸门堵住 |
|---|---|
| 把单次跳变拉到极端 | 段幅上限 `0.8` |
| 童年期先把自己搞残 | 观众权重 `gᵢ`（S1 的 `AUD` 只有 3–8，`gᵢ ≈ 0.15–0.4）` |
| "自残→暴富"刷第二遍 | 套路重复 `rᵢ = 0.5` |
| 一路平顺 / 一路摆烂 | `n < 2` 归零 |

**观众权重是四道里最关键的一道**：它让人生前段——也就是最容易被 min-max 的部分——
在数学上天然廉价，不需要任何额外的反滥用特判。

## 5. 全局反刷分机制清单

设计审查时按这张表核对，缺一项即视为回归：

1. §2 trope 疲劳 `F = 0.6^n`
2. §4.3 段幅上限
3. §4.3 观众权重
4. §4.3 套路重复衰减
5. §4.2 必须多段
6. `05-chapter.md` 腰斩产生的 `注水` 污点（`M × 0.85`）

## 6. 反讽 `Iro` 的标签口径

`Iro` 靠 tag 交集判定，因此 tag 命名必须收敛，否则内容一多就对不上。
规则：**tag 取自 `content/tags.js` 的固定枚举，事件不得自造 tag。**

判定集合：

```
死法 tags  ∩  (开局天赋 tags ∪ 首张人设 tags ∪ S1 事件 tags)
```

命中 0/1/2/≥3 → `1.0 / 1.5 / 2.5 / 4.0`；
死法 trope == 最高收视年 trope → 额外 `+0.5`。

写作要求见 `content/authoring.md`：**每条死法事件必须至少携带 2 个 tag**，
否则反讽乘数永远打不出高值，C2 的第三根柱子会形同虚设。
