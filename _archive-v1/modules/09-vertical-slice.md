# 模块：纵切片范围与验收测试

> 上位：全部。本文是**实现的准入闸门**：纵切片没跑通并通过验收前，不扩内容量。

## 1. 为什么先做纵切片

SYSTEM §8 列的调参项（阈值、桥段区间、评分映射系数）全部依赖实测分布。
先铺 120 条事件再发现评分映射不对，就要重写所有事件的 `drama` 值。

**纵切片的目的是把公式跑出真实数字**，不是把游戏做完。

| **内容契约** | `MANIFEST` + `define/seal` 注册表 + 存档前向兼容 + `dev=1` 调试模式 |
| **信号层** | 仅 CSS 部分：变色/色差、逐字 transform 破碎、数字弹出过冲 |

### 2.2 不包含

| 项 | 理由 |
|---|---|
| 分享卡 Canvas 导出 | 结算页 DOM 先跑通，导出是纯增量 |
| 其余 19 条轨道 | 4 条足以测出 `Com` 的行为 |
| 隐藏第六季 `化神` | 依赖 `xiuxian` 满深度，内容量不够 |
| 图鉴 UI | 数据先记录，界面后做 |
| 梗词库接入 | 纵切片文案用平实中文（`lexicon.md` §8.3 的替代方案）|
| 动效打磨 | 数字跳动要有，缓动曲线不调 |
| NPC 内容量（30–40 个） | 2 个足以验证事件线与退场机制 |
| 开局四项的 T2 / T3 | 只做 T1，分档留到 B 期 |
| 抽卡动画 | 结果正确即可，一键跳过必须能用 |
| canvas 粒子系统 | 信号层 B 期内容（`15-signal-fx.md` §6），推迟不影响 schema |
| 屏幕震动 / emoji 粒子 | 同上 |
| 每局 3–4 个场景的完整内容量 | A 期 2 个场景足以验证时长代价与设计假设 |

三个新系统（开局四项、NPC、抽卡）的**状态模型与 schema 必须进 A 期**，
只有内容量留到 B 期。理由与真结局进 A 期相同：
schema 改动 retrofit 最贵，会推翻已经写好的事件数据。

真结局**必须进纵切片**，因为它是 C7 的封顶石，
且它的判定依赖 `HOOK` 全链路正确——留到后面接会推翻已有事件数据。

## 3. 技术形态（C8）

```
index.html            // 双击即跑
vendor/vue.global.js  // 本地 vendored，无 CDN
src/
  engine/             // 纯逻辑，零 DOM 依赖
    condition.js      // DSL 解析与求值
    state.js          // 状态模型
    scoring.js        // 年度公式 + 三乘数
    run.js            // 主循环、脉冲、季末
    rng.js            // seed 驱动的确定性随机
  ui/                 // Vue 组件
content/              // 数据
test/
  run-tests.mjs       // node 直接跑，无测试框架依赖
```

**engine 层零 DOM 依赖**是硬要求：它必须能在 node 里被批量跑 1000 局，
否则 SYSTEM §8 的调参做不了。

## 4. 自动化验收断言

`node test/run-tests.mjs` 全绿才算通过。

### 4.1 DSL（`03-events.md` §1.3）

1. `AGE>=18` / `MNY>10` 等标量比较正确
2. 数组语义：`CAST=["x"]` 包含、`?` 交集非空、`!` 交集为空
3. **括号分组被真正尊重**：构造一组状态，使 `(A & B) | C` 为真而 `A & (B | C)` 为假，
   两式必须给出不同结果（原作的左到右求值会让二者相同）
4. **同层混用未加括号 → 抛错**：`AGE>18 & MNY>5 | INT>8` 解析即失败
5. 未登记的属性键 → 抛错，不静默当 0

### 4.2 计分（`01-scoring.md`）

6. 结算顺序正确：同一 trope 首次出现 `F = 1.0`
7. trope 第 2 次 `F = 0.6`，第 3 次 `F = 0.36`
8. `M` 计算：`(1 + Σ addMult) × Π xMult`，污点 `×0.85` 参与
9. **单调 `WLOG`（一路上升 / 一路下降）→ `Amp = 0.5`**
10. 段幅超过 `0.8` 被截断
11. 全程低 `AUD`（童年式自残）→ `Amp` 接近下限
12. 同一 (起点 trope, 终点 trope) 组合第二次 → 该段 `× 0.5`
13. `Com`：3 条轨道且全部 `depth ≤ 2` → 强制 `0.5`
14. `Iro`：tag 交集 0/1/2/3 → `1.0/1.5/2.5/4.0`

### 4.3 季末（`05-chapter.md`）

15. `S ≥ 2T` → 加更；`S ≥ T` → 续订；`S < T` → 腰斩
16. 腰斩后：获得 `注水`、`AUD` 砍半、下季阈值 `×1.5`
17. 第 2 次腰斩 → 挂 `烂尾` 标签、继续播到 S5，不提前完结
18. S1 永不腰斩

### 4.4 真结局（`08-true-ending.md`）

19. 四条件全满足 → 触发
20. **"一路选安稳"（`HOOKP < 12`）→ 不触发**
21. 只有低价收手（< 60% 阈值）→ 不触发
22. 收手全在 S3 及更早 → 不触发
23. 触发后：评分为 `null`、污点牌数量不变
24. 不存在任何 cast / talent 的效果字段引用 `HOOK`

### 4.5 内容一致性（`content/README.md` §5）

25–33. 该节 9 条检查全部实现为断言

### 4.6 确定性

34. 同 seed + 同选择序列 → 逐年结果完全一致
35. 同 seed + 不同选择 → 结果不同（seed 不锁死人生）

### 4.7 事件线与分叉（`13-eventlines.md` §7）

36. 每条事件线 `chain` 内事件均存在且 `noRandom === true`
37. 每条 `forks[].chain` 非空，终点事件无 `next`
38. `forks[].from` 落在 `1 … stages-1`
39. **主链终点与每条分叉终点各自至少授予 1 张人设牌**
40. **每条分叉的轨道深度增量 > 0**（增量为 0 等于变相截断）
41. 敏感题材事件线（`kuaxingbie` / `yaowu` / `dilei`）`name === null`
42. **敏感题材事件线的入口 `include` 不引用任何属性键**
    （只允许 `FLAG` / `EVT` / `AGE` / `SEASON`）
43. 走分叉与走主链的玩家，`Com` 乘数不因"选了分叉"而降低
    （构造两条等长路径对比）

断言 40 与 43 是本组的重心：它们保证中途退出是"另一条路"而不是"更少的路"，
从而游戏不会拿分数替一件真实的事表态。

### 4.8 NPC（`10-npc.md` §9）

44. 每个 NPC 的 `eventline` 存在，`track` 与 `scope` 相容
45. 每个 NPC 有且仅有一个退场事件
46. **所有 NPC 事件 `noRandom === true`**（不进通用池，结构上排除撞车）
47. 所有 NPC 事件的 `include` 引用了 `NPC` 或 `NPCAX`
48. `bio` / `voice` / `never` 三字段非空
49. 同时在场 NPC 数量 ≤ 5

### 4.9 开局四项（`11-origin.md` §10）

50. 每个家庭项的旗标被至少一条轨道入口或事件的 `include` 引用
51. **每个性格项同时有正向与负向字段**
52. 观众汇率表对两个性别都非空，且**各有至少一项 < 1.0**（双向不对称）
53. **无任何轨道入口的 `include` 引用 `SEX`**（门槛必须性别中性）

### 4.10 抽卡（`12-gacha.md` §8）

54. 每个条目的 `target` 存在于对应内容表
55. 每个 `scopes` 值都在 `tracks.js` 的 `lexiconScope` 枚举内
56. T2 / T3 内容项各被恰好一个抽卡条目覆盖
57. **抽卡池不含任何 `type: 'ending'` 条目**（真结局红线）
58. 每个条目 `dupValue > 0`（重复必须有转化）

### 4.11 场景模式（`16-scenes.md` §10）

59. `scenes[stage].beats` 内事件存在、`kind === 'beat'`、`noRandom === true`
60. `beats` 长度在 **3–6** 之间；`scenes` 键落在 `1…stages`
61. 每个 beat 文本 **≤ 30 字**
62. 每场景带 `options` 的节拍数在 **1–2** 之间
63. **任一局可能遇到的场景数 ≤ 4**（引擎常量，不可内容配置）
64. **带 `restraint` 的节拍与其 `escalate` 选项在同一节拍内**
    （否则"放弃 N 分"算不出来）
65. 节拍内计分累加正确：`B` 逐节拍递增、`M` 在场景内保持不变

### 4.12 内容扩展契约（`14-content-api.md`）

66. `BH.MANIFEST` 是浏览器与 node 共用的唯一清单
    （node 侧断言：清单里每个文件都能被加载）
67. **注册顺序无关**：打乱 `MANIFEST` 顺序后 `seal()` 结果一致
68. 重复 id 注册 → 抛错，错误信息含两次注册的来源
69. `seal()` 后写注册表 → 抛错（已冻结）
70. `condProp` 注册的新键可被 DSL 正常引用；与已有键冲突 → 抛错
71. **存档前向兼容**：存档含不存在的已解锁 id 时静默丢弃，不崩溃、
    `material` 不清零
72. `dev=1` 下的结算**不产出素材、不解锁内容**，且写入独立存档键

### 4.13 叙述层禁用词（`content/authoring.md` §8.1）

73. 扫描全部事件 `text` / `options[].text` / 死法文本 / 结局文本，
    命中"情绪定性""价值判断""说教连接"三组词即失败
74. 引号 `「」` `""` 内内容跳过检查（角色台词与心理活动豁免）
75. **心理活动内部仍检查"说教连接"组**
    （`你想，原来这才是最重要的` 必须被拦下）
76. 恐怖 / `lingyi` 事件正文同样受禁用词表约束
    （信号层负责表现恐怖，文字不许表态，`authoring.md` §1.5.1）

## 5. 调参跑（SYSTEM §8）

纵切片跑通后执行：

```
node test/tune.mjs --runs 1000 --strategy random --seed TUNE00
node test/tune.mjs --runs 200  --strategy greedy --seed TUNE00
```

验收目标：

| 策略 | 评分要求 |
|---|---|
| random | 中位数落在 3.0–4.0 |
| greedy（每次选桥段最高项） | 不超过 7.5 |
| greedy | **腰斩率 > 0**（贪心不能无脑通关）|
| random | 真结局触发率 ≈ 0（不能被瞎点撞出来）|

不达标则回填 SYSTEM §8 的系数，**不改公式结构**。

### 5.1 平衡检查（新增）

以下三项与上表同等级，不达标同样阻塞闸门：

| 检查 | 要求 |
|---|---|
| **性别净期望** | 1000 局随机策略按性别分组，评分**中位数之差 ≤ 0.3** |
| **逐属性贡献可见** | 报告必须逐属性输出"两个性别下的平均收视贡献"，不强制相等但必须输出 |
| **事件线不得是捷径** | 跨性别线的期望收视贡献落在**普通轨道的同一区间内** |
| **时长分布** | 熟练局中位数 **≤ 170 秒**；超标优先削非场景决策点，不削场景 |
| **脉冲分布** | 总脉冲落在 45–60，场景占 3–4 个决策点 |

不达标时调整事件池桥段基数与观众汇率，**不改公式结构**。

第二项防的是"总分平了但内部废掉一半属性"——
总分持平、可是女性的 `STR` 完全无用，那仍然是设计失败。

第三项防的是题材被工具化：那条线可以是有分量的，不可以是划算的
（`13-eventlines.md` §5.3）。

## 6. 人工验收

自动断言测不了的部分，逐条手过：

1. 手机竖屏一屏内能读完任意一条事件
2. 熟练局能压到 150 秒内（自己连点计时）
3. 数字跳动看得见连锁，`F = 0.6` 时 UI 明确显示"观众看腻了"
4. 收手选项显示"放弃 N"，且 N 是本年最高潜在收视的实际值
5. 隐秘轨道入口选项读起来像普通选项（找一个没看过文档的人试）
6. 结算页 3 秒内出现，不滑动即可看到剧名 + 评分 + 标签
7. 剧名在 100 个不同 seed 下重复率 < 5%
8. 真结局文本过 `authoring.md` §6 三问，且不含 §5 禁用词
9. 真结局结算页无任何"恭喜/成就/解锁"字样
10. 抽查 20 条事件正文：叙述层零评价，冷幽默来自并置而不是形容词
11. 走跨性别线的分叉与走主链，**读起来都像"另一套"而不是"更少"**
    （找一个没看过文档的人分别玩一遍）
12. 抽卡能一键跳过，不阻塞"再来一局"
13. **场景让人觉得"进入了一件事"**，而不是连点四下过场
14. **加码/收手场景里，第五下的"放弃"比单点事件明显更重**
    （这是场景模式值不值得它时长代价的唯一判据）
15. 所有动效**点击可打断**，无打字机效果，文本立即全量显示
16. `prefers-reduced-motion: reduce` 生效：关抖动与粒子，保留变色
17. 信号劣化有**非颜色线索**（字符错位 / 字重变化），色觉障碍玩家能接收到
18. 手机竖屏实机 60fps，无明显掉帧
