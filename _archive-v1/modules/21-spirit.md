# 模块：精神指数

> 上位：`docs/SYSTEM.md` §0.1（五维）、`docs/BRIEF.md` C2（乏味不得分）、
> C4（敏感题材克制处理）。

## 0. 不加第六个属性

需求是"加一个精神指数"。**实现方式是把现有的 `心(SPR)` 做成精神指数，
不新增第六维。**

理由三条：

1. `SPR` 目前是全五维里最闲的一个——被事件反复扣减，但没有任何门槛引用它
2. 加第六维要占 UI 一整行（手机竖屏），且平衡面翻一倍
3. **双向门槛天然实现 C2**：两端都开内容，中间什么都没有。
   "过得平平稳稳"在机制上就是无事发生

## 1. 五档带

```
        崩溃          消沉        常态         敏锐        超载
      ≤ 0          1 – 4      5 – 11     12 – 16      ≥ 17
   ├──────────┼──────────┼───────────┼──────────┼──────────┤
   抑郁 / 灵异    低落事件     什么都没有    修仙 / 魔法   走火入魔
```

| 带 | 键 | 范围 | 开什么内容 |
|---|---|---|---|
| 崩溃 | `crash` | ≤ 0 | 抑郁线、灵异线（现实感松动）、垮掉 |
| 消沉 | `low` | 1–4 | 低落类 flavor、逃避型选项 |
| **常态** | `flat` | **5–11** | **无特殊内容** |
| 敏锐 | `keen` | 12–16 | 修仙入口、魔法入口、感知类事件 |
| 超载 | `over` | ≥ 17 | 走火入魔、分不清现实（从另一端回到失控） |

### 1.1 中间档是刻意的空

`flat` 带（5–11）**不提供任何专属内容**。这不是没写，是设计。

`BRIEF.md` C2 的原话是"游戏否定的是乏味"。精神指数停在中间，
意味着玩家既没有崩，也没有走远——那正是最没戏的活法，
所以它在内容上就是一片空白。

玩家会自己发现：想要东西发生，`SPR` 必须离开中间。
往哪边走都行，但不能不动。

### 1.2 两端都失控，但方式不同

这是本模块最重要的设计对称：

| | 崩溃带 | 超载带 |
|---|---|---|
| 失控的是 | **世界**（现实感松动） | **你**（走得太远） |
| 表现层 | 信号层劣化（`15-signal-fx.md`） | 文本内容层的失真 |
| 轨道 | `lingyi` 灵异 | `mofa` 魔法 / `xiuxian` 修仙深层 |
| 收视特点 | `AUD` 波动大，桥段高 | 倍率高，但 `STR` 掉得快 |

两端都通向奇观，中间通向什么都没有。这个形状本身就是本作的态度。

## 2. 与轨道门槛的对应修订

`04-tracks.md` 初版把 `mofa` 的入口写成"`SPR` 极低（分不清现实）"。
**修订为高档**，理由是与 `lingyi` 区分：

| 轨道 | 新门槛 | 语义 |
|---|---|---|
| `lingyi` 灵异 | `SPR <= 0` | 世界出问题（信号层） |
| `mofa` 魔法 | `SPR >= 12` | 你感知到别人感知不到的 |
| `xiuxian` 修仙 | 旗标 + `SPR >= 10` | 需要养得住心 |
| 走火入魔 | `SPR >= 17` | 从敏锐一端跌回失控 |

`lingyi` 与 `mofa` 因此不再重叠：**一个是媒介坏了，一个是你变了。**

## 3. 地雷系：同现而非因果

需求里提到"精神指数低了容易地雷系"。这一条**不按字面实现**，
而是反过来接：

| 做法 | 采用 |
|---|---|
| 用低 `SPR` 当**入口门槛** | ✗ 不做 |
| 走这条线**会拉低** `SPR` | ✓ 做 |

区别是：前者断言"这个亚文化是精神状态差的症状"，后者只陈述
"这条路会消耗你"。机制上你想要的关联仍然存在——
玩地雷系线的人精神指数确实会低——但游戏没有把它说成因果。

入口保持 `04-tracks.md` §8.5 的纯事件链 + 高中窗口，不引用任何属性键。
该约束已做成机器可验证规则（`13-eventlines.md` §7 第 8 条）。

## 4. 抑郁：内容处理红线

崩溃带开放抑郁线。它适用 `C4` 全部红线，另加两条：

| 规则 | 说明 |
|---|---|
| **不写成剧情奖励** | 桥段基数与其他线同档，不给额外倍率 |
| **不写康复弧线** | 不做"通过努力战胜它"的叙事，那是说教 |
| 写状态与后果 | 不写过程与方法；不出现任何具体手段 |
| 不浪漫化 | 不写成敏感、深刻、艺术气质的来源 |
| 有分叉退出 | 与其他敏感线一致（`13-eventlines.md` §3） |

register 参照（只示范语气）：

```
✓  你把闹钟从六点改到六点半，又改回六点。两个都没响，因为你醒着。
✗  你陷入了深深的绝望之中。
```

第二句同时踩了三条：情绪定性（绝望是禁用词）、替玩家表态、无具体细节。

## 5. 机制接口

### 5.1 新增 DSL 属性

| 键 | 类型 | 说明 |
|---|---|---|
| `SPRBAND` | 标量 | 档位序号 `0`崩溃 `1`消沉 `2`常态 `3`敏锐 `4`超载 |
| `SPRLOW` | 标量 | 本局是否进过崩溃带（`0`/`1`），用于回响 |
| `SPRHIGH` | 标量 | 本局是否进过超载带（`0`/`1`） |

用序号而不是字符串，是为了让 `SPRBAND<=1` 这类区间条件写得出来。
内容层用 `SPRBAND=0` 判崩溃、`SPRBAND>=3` 判敏锐以上。

`SPRLOW` / `SPRHIGH` 只增不减，这样后期能写出
"你有过那么一段"的回响事件，而不需要玩家当下仍在那个带里。

### 5.2 养心与耗心必须都有途径

双向设计要求两个方向都走得通，否则它退化成单向。

| 方向 | 途径 |
|---|---|
| 耗心 | 加码选项、职业 `wear`、腰斩、污点 |
| **养心** | 收手选项、季末奖励、特定职业（`看山的`）、部分 flavor |

初版的问题是**只有耗没有养**：高桥段选项几乎都扣 `SPR`，
而恢复途径几乎不存在，于是所有构筑最终都滑向崩溃带。
敏锐带形同不存在。

修正后收手选项统一给 `SPR +1 ~ +2`——这同时强化了 C7：
**收手不只是放弃分数，它是唯一稳定的养心途径。**
想走修仙/魔法的玩家必须学会收手，而收手正是真结局的必要条件。
两条设计线在这里合流，不是巧合。

## 6. 一致性检查

补进 `content/README.md` §5.1：

1. `mofa` / `xiuxian` 入口引用 `SPR` 或 `SPRBAND` 的高档，不引用低档
2. `lingyi` 入口引用崩溃带
3. **`dilei` 入口不得引用 `SPR` / `SPRBAND`**（§3）
4. 抑郁线的桥段基数不超过普通轨道同类事件上限（不做成剧情奖励）
5. 抑郁线必须有分叉退出，且分叉终点授予人设牌
6. 每季至少 2 条给 `SPR` 正增益的事件或选项（养心途径必须存在）
7. `flat` 带（`SPRBAND=2`）**不得有任何专属事件**——中间档的空是设计
