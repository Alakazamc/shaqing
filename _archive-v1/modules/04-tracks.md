# 模块：轨道

> 上位：`docs/BRIEF.md` C4 C5、`docs/SYSTEM.md` §5。

## 1. 轨道是什么

轨道是一条人生的**题材方向**。它同时承担三个职责：

1. **构筑方向** — 决定能拿到哪些人设牌，影响 `Com`（贯彻乘数）
2. **梗的投放通道** — 二次元轨道吃二次元梗，鼠鼠轨道吃鼠鼠梗（C5）
3. **发现感的载体** — 隐秘轨道是"等等，这游戏能修仙？"的来源（C4）

数据结构：

```js
{
  id: 'xiuxian',
  name: '修仙',
  emoji: '🧘',
  hidden: true,               // 是否隐秘轨道
  maxDepth: 5,
  socialWeight: 0.6,          // 每级深度贡献的"社会位置"
  lexiconScope: 'xianxia',    // 该轨道使用的梗词库圈层
  entry: 'INT>8 & AGE?[9,10,11,12]',   // 入口门槛（状态，不是概率）
}
```

## 2. 深度与社会位置

`depth` 由选项的 `track: { id: +1 }` 累加，上限 `maxDepth`。

SYSTEM §3.1 的水位公式需要 `社会位置 ∈ [0, 10]`：

```
社会位置 = clamp( Σ(轨道 depth × socialWeight) + 旗标加成, 0, 10 )
```

`socialWeight` 让不同轨道对"水位"的贡献不同：
`公务员` 轨道每级 +1.2（社会地位实打实上升），
`地下说唱` 每级 +0.3（圈内地位高但水位不动）。
这让振幅计算能区分"世俗意义的起落"和"圈内起落"。

### 4.0 `lingyi` 与 `mofa` 的区分

两条都是"现实出问题"，但机制上不重叠：

| 轨道 | 出问题的是 | 入口 | 表现手段 |
|---|---|---|---|
| `mofa` 魔法 | **你**——走得太远 | `SPRBAND >= 3` 敏锐带 | 文本内容层面的失真；事件线终点以人设牌延寿 |
| `kehuan` 科幻 | **时间**——被当成可保存的资源 | `AGE >= 25 & INT >= 10` | 低温、样本与回访形成事件线；终点以人设牌延寿 |
| `lingyi` 灵异 | **信号**——播出这部剧的媒介 | `SPRBAND = 0` 崩溃带 | 独占信号层效果（`15-signal-fx.md`） |

> **修订**：初版把 `mofa` 的入口写成"`SPR` 极低（分不清现实）"，
> 与 `lingyi` 重叠。改为敏锐带之后两者不再撞车：
> **一个是媒介坏了，一个是你变了。** 详见 `21-spirit.md` §2。

`lingyi` 是信号层视觉效果的主要载体，也是它唯一的独占轨道。
入口是纯剧情链、不设属性门槛，因为它不该被读作"你精神有问题"。

### 4.1 敏感题材的处理红线（C4）

`dilei` / `kuaxingbie` / `yaowu` 三条轨道，以及所有自毁类事件：

- **写状态与后果，不写过程与方法。** 不出现任何具体物质名、剂量、手法。
- **不浪漫化，也不说教。** 不写成美学，也不写成警示教育。
- **不猎奇。** 不用这些题材制造奇观段落，它们的桥段基数与其他轨道同档。
- `kuaxingbie` **不设属性门槛**，因为把它绑定在"心低"上就是在暗示病理化。
  它的入口是纯剧情链，与其他轨道一样有正常的深度与人设牌。
  注意这与"开局性别影响属性"不冲突：**开局性别给属性画像**，是出身设定；
  **把轨道入口挂在某个属性上**，是在给因果关系下判断。前者做，后者不做。
  该约束已做成机器可验证规则，见 `13-eventlines.md` §7 第 8 条。
- 这三条轨道**必须实现为带分叉退出的事件线**，不得实现为可中断的线性链。
  理由与分叉规则见 `13-eventlines.md` §3；跨性别线的阶段结构见其 §5。
  一句话版本：中途退出必须是"另一条完整的路"，不能是"更少的路"，
  否则贯彻乘数 `Com` 会让游戏拿分数替一件真实的事表态。
- `yaowu` 轨道 id 与显示名一律用含蓄命名（🌙），
  终点事件的死亡描写留在"没有人第二天叫醒他"这一层。

审查方式：这三条轨道的所有文案由 `content/authoring.md` 的基调判定问句单独复核一遍。

### 4.2 可发现性四条规则（SYSTEM §5 展开）

1. **文本层永不打标签。** `跟着那个老头去后山` ✓ / `【修仙】拜师` ✗
   不给图标、不给稀有度描边、不给"这个选择很重要"的提示音。
2. **门槛是状态，不是低概率随机。** 可攻略、可复现、可用 seed 分享。
3. **每局保底暴露 ≥1 条。** 具体哪条由 seed 决定。玩家不一定点，但一定看见。
   实现方式：脉冲抽取时若本季尚未出现任何 `hidden` 轨道入口，
   在最后一个决策点强制把一条门槛已满足的入口塞进选项。
4. **图鉴显示未知计数。** `已发现 6 / 23` + 一排 `???`。
   **例外：真结局槽位完全空白，不计入分母**（C7）。

## 5. 梗的圈层投放（C5）

每条轨道绑定一个 `lexiconScope`。事件文案引用梗词条时，
**只能引用当前轨道 scope 或 `common` scope 的词条**。

理由（BRIEF C5 已定）：窄梗在圈内的转发率高于泛梗，而截图正是在圈内传播的。
二次元梗有九成玩家看不懂——这不是缺陷，是让轨道各自吸引各自的圈层。

工程约束：

- 词条集中在 `docs/content/lexicon.md`，实现层镜像为 `content/lexicon.js`
- 每条标注圈层与**过期风险等级**
- 高风险梗只出现在可替换的文案槽位
- **梗绝不写进机制名称**：轨道 id、人设牌 id、字段名一律用中性词
  （所以是 `cast_chouxiang` 而不是某个具体的当期热梗）

## 6. 贯彻乘数对轨道的影响

`Com`（SYSTEM §3.2）用主导轨道的 `p`（纯度）与 `d`（深度比）计算，
并对"涉及 ≥3 条轨道且全部 `depth ≤ 2`"强制罚到 `0.5`。

设计含义：**换轨道有代价。** 玩家要么一条道走到黑（高 `Com`），
要么走 `双重人格` 那种明确奖励分裂的构筑（`02-cast.md` §5 反义咬合），
不存在"随便都试试"的中间地带。这是 BRIEF C2 "半途而废的修仙者不如走火入炉的"的实现。

## 7. 性别与轨道：同门槛，不同事件

开局性别影响属性与事件（详见 `11-origin.md`），但**不影响任何轨道的入口门槛**。

规则：

```
颜 8  →  两个性别都能开偶像/饭圈轨道，门槛完全相同
         但进去之后抽到的事件池不同
```

同理 `体 8` 对两个性别都开竞技轨道。

**同一属性、同一门槛、不同事件、不同代价。**
这样 `颜` 和 `体` 对两个性别都是硬通货，谁的构筑空间都没有被削掉一半。

反面做法（已否决）：把 `颜` 设成女性属性、`体` 设成男性属性。
那等于说男的不需要颜值、女的不需要身体——现实上不成立，
机制上则直接砍掉每个性别一半的轨道入口。

### 7.1 属性画像的中途迁移

`kuaxingbie` 轨道会在推进过程中改变属性画像，
因此会改变水位曲线的走法，在数学上确实影响振幅 `Amp`。

这是机制的自然结果，但由此产生一个必须堵住的风险：
**这条线不能成为高分捷径**，否则题材被工具化。
调参约束见 `13-eventlines.md` §5.3。

## 8. 分水岭事件：轨道之间的现实因果

### 8.1 要解决的问题

轨道入口目前挂在旗标与属性上，能用，但**缺少叙事因果**。
玩家不会觉得"因为我考不上大学，所以去做了网红"，
只会觉得"某个选项出现了"。

`BRIEF.md` §1 写明本作的灵魂是**选择 → 后果 → 新的选择**。
少了中间那个"后果"，链子就是断的。

### 8.2 分水岭的定义

**分水岭事件**：一个固定年份触发、结果由前情决定、
并把玩家分流到若干条互斥轨道的事件。

三个必要条件：

| 条件 | 说明 |
|---|---|
| **固定年份** | 不是随机出现，玩家可以预期它要来 |
| **结果由前情决定** | 属性 + `EVT` + `FLAG` 共同判定，不掷骰子 |
| **分流是互斥的** | 走了一条，其余当年不可达 |

第二条是关键：分水岭**不能是随机的**。
"我没考上"必须是前面十几年选择的结果，否则后果没有意义。

### 8.3 第一个分水岭：18 岁的那场考试

```
        ┌─ 分数够 ──────► 读书轨道继续（大学）
        │
18 岁 ──┼─ 差一点 ──────► 复读（再来一年，压力事件池）
        │
        ├─ 没考上 ──┬───► 网红        （明面）
        │           ├───► 说唱        （半隐秘）
        │           ├───► 打工 / 流水线（明面）
        │           └───► 鼠鼠        （明面）
        │
        └─ 没参加 ──────► 已在异常轨道 / 中专分流的既定路径
```

判定用 `INT` 与前情：

| 结果 | 条件 |
|---|---|
| 分数够 | `INT >= 12` 或（`INT >= 9` 且有 `f_liuxia`） |
| 差一点 | `INT` 9–11 |
| 没考上 | `INT <= 8` 或有 `f_zhongzhuan` |

**"没考上"不是失败分支，是内容最厚的分支。** 它通向四条轨道，
而"考上了"只通向一条。这个不对称是刻意的：
本作的题材密度在偏离主干的地方，不在主干上。

### 8.4 网红轨道（明面，不隐秘）

`wanghong` 必须是**明面轨道**。理由：考不上大学去做网红是写实的，
不是奇观。把它做成隐秘轨道会误导玩家以为它是彩蛋。

| 属性 | 值 |
|---|---|
| `maxDepth` | 5 |
| `socialWeight` | 0.5（圈内地位高但水位不动） |
| `lexiconScope` | `wanghong` |
| 特点 | `AUD` 增长最快的轨道，但 `SPR` 磨损也最快 |

它是全局最容易堆高 `A = AUD/10` 的路径，因此也是最容易撞
疲劳系数 `F` 的路径——你必须不停换花样。

### 8.5 高中是地雷系的自然窗口

`dilei` 的入口条件从"`SPR` 低 + 少年期特定链"改为
**纯事件链 + 高中阶段（15–17 岁）**。

理由与 `kuaxingbie` 相同（§4.1）：把入口挂在"心低"上，
等于用机制断言这类身份源于精神状态不好，那是病理化。

改后的入口是三条并行的事件链任一：

| 链 | 触发 |
|---|---|
| 关系链 | 高中期某段关系的走向 |
| 表达链 | 开始在网上写东西 / 换外形 |
| 孤立链 | 转学 / 换班之后的处境 |

三条都不引用任何属性键，只引用 `AGE` / `FLAG` / `EVT`。
这条约束已做成机器可验证规则（`13-eventlines.md` §7 第 8 条）。

**内容红线不变**（`content/authoring.md` §4）：写状态与后果，
不写过程与方法；不浪漫化，也不说教；不猎奇；不用梗。
