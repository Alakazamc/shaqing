# 模块：稀有度体系

> 上位：`docs/modules/02-cast.md` §3（人设牌稀有度已定）、`docs/modules/12-gacha.md`。
> 本文把稀有度从"只有人设牌有"扩成**全局统一体系**，并定死配比。

## 1. 四档与配比

```
普通 common   ─ 稀有 rare ─ 史诗 epic ─ 传说 legend
```

适用对象：**人设牌、天赋、家庭、性格、职业、NPC**。

### 1.1 池内数量配比

| 档 | 占比 | 说明 |
|---|---|---|
| `common` | **50%** | 底座。保证任何时候池子里都有大量可抽内容 |
| `rare` | **32%** | 主体验层 |
| `epic` | **14%** | 构筑转折点 |
| `legend` | **4%** | 一局能碰到 0–1 张 |

### 1.2 抽卡命中率（`12-gacha.md` 的档位权重按此校准）

基础命中率（评分 3.0 时）：

| 档 | 基础率 | 评分 6.0 时 |
|---|---|---|
| `common` | 62% | 44% |
| `rare` | 28% | 34% |
| `epic` | 8.5% | 17% |
| `legend` | 1.5% | 5% |

**评分只抬高档位权重，不作为解锁门槛**（`12-gacha.md` §3.1）：
低分玩家仍有 1.5% 摸到传说，只是慢。

### 1.3 保底

| 保底 | 规则 |
|---|---|
| 软保底 | 连续 8 抽未出 `epic` 及以上 → 下一抽 `epic` 权重 ×4 |
| 硬保底 | 连续 20 抽未出 `epic` 及以上 → 强制出 `epic` 或更高 |
| 重复保护 | 抽到已解锁 → 转素材，且计入保底计数 |

硬保底是必须的：纯概率会产生"我抽了 30 局什么都没出"的挫败，
而本作的留存逻辑建立在"再来一局是愉快的"。

## 2. 数值强度与稀有度的对应

**稀有度只决定"多难拿到"，不无限决定"多强"。**
硬上限仍然是 `01-scoring.md` §3.2：
单张牌不得让 `M` 超过 4.0；`M > 8` 必须是至少 3 张牌咬合的结果。

| 档 | 人设牌 | 天赋 | 家庭 / 性格 |
|---|---|---|---|
| `common` | `addMult` +0.2 – +0.4 | 单属性 +2 – +3 | 常规出身 |
| `rare` | `addMult` +0.5 – +0.9 | 双属性或小倍率 | 有具体设定的出身 |
| `epic` | `addMult` +1.0 – +1.5 或 `xMult` ×1.5 – ×2.0 | 条件式倍率 | 离谱但可信 |
| `legend` | `xMult` ×2.5 – ×3.0（多带条件） | 改写规则 | 荒谬 |

`legend` 的定位是**改写规则**而不是堆数值。基准例：
`反社会人格` 让每张污点 `+1.0` 倍率——它没有直接给倍率，
它把"污点是惩罚"这条规则反转了（C3）。

## 3. 视觉编码（C8：零美术资产）

只用 CSS 变量与 emoji，不加图片：

| 档 | 主色 | 描边 | 附加 |
|---|---|---|---|
| `common` | `--ink-dim` 灰 | 无 | — |
| `rare` | `--cool` 蓝 | 1px | — |
| `epic` | `#b07bd8` 紫 | 1px + 内发光 | 抽出时轻微缩放过冲 |
| `legend` | `--accent` 金 | 1px + 外发光 | 抽出时屏幕短暂压暗 + 金色粒子 |

**颜色不能是唯一信息载体**（`15-signal-fx.md` §5）：
每档同时显示档位名（普通 / 稀有 / 史诗 / 传说），不只靠颜色区分。

## 4. 一致性检查

补进 `content/README.md` §5.1：

1. 每个人设牌 / 天赋 / 家庭 / 性格 / 职业 / NPC 都有合法 `rarity`
2. 各档在池内占比落在 §1.1 的 ±8 个百分点内
3. `legend` 档条目数 ≥ 1 且 ≤ 池的 8%
4. 每档的数值强度落在 §2 的区间内（人设牌与天赋）
5. 抽卡池条目的 `tier` 与目标内容的 `rarity` 一致
   （不允许"史诗牌挂在 T1 抽卡条目上"）
