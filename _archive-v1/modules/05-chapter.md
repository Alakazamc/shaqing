# 模块：季末结算、腰斩、死法

> 上位：`docs/SYSTEM.md` §1.3 §1.4 §4。

## 1. 季末结算流程

```
1. 汇总 S_season = Σ R_year
2. 与阈值 T_season 比较 → 加更 / 续订 / 腰斩
3. 播放结算面板（收视曲线 + 本季高光年 + 新增人设牌）
4. 若腰斩 → 注水续命分支
5. 检查隐藏第六季解锁条件
6. 进入下一季，AUD 与属性带入
```

阈值表（已按 SYSTEM §8 的 2026-08-02 实测回填）：

| 季 | 年龄 | `T_season` |
|---|---|---|
| S1 试镜 | 0–11 | 无（不腰斩）|
| S2 出道 | 12–17 | 90 |
| S3 当红 | 18–29 | 700 |
| S4 中年 | 30–49 | 30 000 |
| S5 收尾 | 50–70 | 无（终局）|

实际阈值 `T_effective = T_season × 1.5^(已腰斩次数)`。

## 2. 加更

`S ≥ 2 × T_effective` → 本季追加 2–4 年（追加年数由 seed 决定）。

文本用制作方口吻，且必须是笑点而不是奖励播报：

> 平台看了数据，追加了投资。你多活了三年，合同上写着"内容方向不变"。

加更的实际收益是**更多脉冲＝更多分**，且延后进入下一季的阈值检查，
所以它是复利型奖励——这符合小丑牌"雪球滚起来就停不下"的手感。

## 3. 腰斩与注水续命 `[BRIEF Q1]`

**腰斩不是死亡，是烂剧的续命手段。** 游戏用离谱方式强行续订：

| 续命桥段 | 文本方向 |
|---|---|
| 穿越 | 醒来发现自己回到了三年前，编剧说这叫"重启" |
| 失忆 | 你忘了上一季发生的事。观众也忘了 |
| 失散多年的双胞胎 | 你其实有个哥哥。他现在是主角 |
| "那是一场梦" | 上一季不算了。制作方发了一条道歉声明 |

代价：

- 获得污点牌 **`💧注水`**（永不移除，可叠加，每张 `M × 0.85`）
- `AUD` 砍半
- 下一季阈值 `× 1.5`
- **累计第 2 次腰斩 → 当场挂上 `烂尾` 标签**，但**剧照样播到 S5**

> **修订**：初版是"第 2 次腰斩 → 提前完结"。这违反 `SYSTEM.md` §1.35
> 的完整度要求——被截断的人生走不到反讽结算，结算页拿不出手，`C6` 断掉。
> 现在腰斩可以无限次发生，代价是污点越堆越多、阈值越抬越高，
> 分数被压到底，但玩家一定能看完自己这条命。
> `烂尾` 从"终止条件"变成"一个可截图的标签"。

### 3.1 这条机制如何满足 C3

`注水` 是污点牌，所以在吃污点的构筑下（`反社会人格` 每张污点 `+1.0` 倍率、
`破罐破摔` 污点 ≥5 时 `×2.0`），**被腰斩是构筑燃料**，
玩家会主动把某一季搞垮去换污点。

计分公式于是自己否定了自己设定的失败条件。态度不靠旁白表达（C3）。

### 3.2 为什么 S1 不腰斩

两个理由，都不可让步：

- 开局就被腰斩会毁掉"再来一局"的冲动，而 C6 要求再来一局的成本为零
- `AUD` 在 S1 只有 3–8，S1 的数值天然不值钱，
  **不需要再叠一层失败惩罚**（`01-scoring.md` §4.4）

## 4. 隐藏第六季

`S6 化神`（50 岁后触发，需 `修仙` 轨道 `depth = 5` 且持有 `cast_zhuji`）。

- 年龄上限扩到 100+
- 属性上限解锁到 30
- 死法事件池切换为奇观死法（`飞升失败`、`雷劫`、`肉身成圣但没人看`）

这是全游戏最强的分数上限，也是最强的"等等，这游戏能修仙？"的转发素材（C4）。
图鉴里在解锁前显示为 `???`。

## 5. 死法事件

死亡是**内容驱动**的，不是寿命耗尽（SYSTEM §1.4）。触发条件：

| 触发 | 说明 |
|---|---|
| 到达寿命上限 | 从死法池抽，按 tag 与前情匹配 |
| 特定事件 | 事件本身即死亡（刻意设计的高潮）|
| 轨道终点 | 走满 `maxDepth` 后的轨道专属死法 |

**`STR ≤ 0` 不再致死**（`SYSTEM.md` §1.35）。它改为「垮掉」：

| 垮掉的后果 | 值 |
|---|---|
| `STR` 钳制 | 不再低于 1 |
| 污点 | 获得 `🩼旧伤`（首次） |
| 观众 | `AUD -6` |
| 后续磨损 | 减半（已经垮了，扣不动了） |

"身体已经废了但你还在演"完全符合本作基调，而且它是可以被吃污点的构筑
反过来利用的——截断式死亡做不到这一点。

### 5.1 死法事件的硬要求

死法事件是 `Iro`（反讽乘数）唯一的判定来源，所以：

- **每条死法事件至少携带 2 个 tag**（`01-scoring.md` §6）。
  少于 2 个 tag 的死法事件视为内容缺陷，纵切片验收会检查这一项。
- tag 必须取自 `content/tags.js` 固定枚举，不得自造
- 死法文本要与轨道呼应：修仙轨道死于雷劫，说唱轨道死于一场没人到场的演出

### 5.2 反讽的设计意图

`Iro` 最高 4.0（+0.5 首尾呼应），是三个乘数里最大的单一杠杆。
这是刻意的：它奖励**玩家有意识地为自己的人生设计一个收尾**，
而不是打完就死。BRIEF C2 原话是"铺垫与收尾对上"。

于是高分玩家的行为模式是：前期埋 tag，后期挑死法。
这个行为本身就是"把人生当剧来写"的具身化——玩家在扮演编剧，不是在扮演人。
