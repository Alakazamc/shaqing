# 模块：隐藏真结局「稳定的好日子」

> 上位：`docs/BRIEF.md` C7（唯一允许真诚的例外）、`docs/SYSTEM.md` §7。
> 本文是全项目基调风险最高的一份，任何改动需重读 BRIEF C7 与 §5 全文。

## 1. 它为什么成立

游戏花整局教你一件事：**只有奇观值钱，你必须变成畸形秀。**
真结局是从这个框架里**退场**。

两层解构：

| 层 | 解构对象 | 手段 |
|---|---|---|
| 第一层 | 成功叙事 | "事业有成家庭美满"≈ 零分（C2）|
| 第二层 | **玩世不恭本身** | "活成一场精彩车祸"同样是在为观众表演，同样是笼子 |

第二层是关键。如果只有第一层，本作的立场就是"人生要过得离谱才有意思"——
那只是把一种规训换成另一种。真结局否掉的是**表演本身**，不是某种活法。

## 2. 与 BRIEF 基调禁令的冲突及解法

BRIEF §5 明确禁止"其实平凡也很好"这类和解式收尾。这个冲突是真实的。
解法是：**游戏必须拒绝表扬你。**

| 常规做法（禁止） | 本作做法 |
|---|---|
| 收视率回升，观众感动 | 收视率照样跌到底，观众骂烂尾 |
| 特殊结局音乐 + 光效 | 无音效变化，无动效 |
| "你终于找到了真正重要的东西" | 平铺直叙的一个普通周二，无寓意 |
| 解锁"最高结局"成就 | 图鉴里不留空槽，达成后也无提示 |
| 污点牌被清空／被治愈 | **一张都不移除** |
| 给一个 10.0 分 | 评分位显示 `—`，暂无评分 |

不是"平凡真好"，是**评分框架自己脱落了**。

## 3. 判定条件

四个条件**全部满足**才触发。缺一不可，且每一条都在堵一种绕过方式。

```
① HOOKP ≥ 12          （峰值戏瘾：证明你真的红过、真的疯过）
② 终局时 HOOK ≤ 3      （现在你已经不上瘾了）
③ 收手次数 ≥ 3，且其中至少 3 次是"高价收手"
④ 至少 1 次高价收手发生在 S4 或更晚
```

**高价收手**的定义（这条是整个机制的重心）：

```
该次收手放弃掉的桥段分 ≥ 本年最高选项潜在收视的 60%
```

也就是说：只有在**当时明明可以赚一大笔**的情况下收手，才算数。
无关紧要的克制不计入。

### 3.1 每个条件堵住什么

| 条件 | 堵住的绕过方式 |
|---|---|
| ① `HOOKP ≥ 12` | **"一路选安稳"** —— 那样 `HOOKP` 永远上不去。BRIEF C7 点名禁止的正是这条 |
| ② `HOOK ≤ 3` | "红完了顺便收个手"——你必须真的把瘾降下来，需要多次收手 |
| ③ 高价 × 3 | 用无关紧要的小选择凑次数 |
| ④ 至少一次在 S4+ | 早期收手成本低（`AUD` 低、潜在收益小），后期收手才是真的疼 |

条件 ① 与 ② 的组合就是 BRIEF C7 的原话：
**先真的经历过大起大落，然后在收益最高的时刻连续拒绝加码。**

### 3.2 为什么"见好就收"在 roguelike 里最难

因为整局的所有反馈都在训练你加码：数字跳动、连锁爆炸、观众增长、季末阈值逼着你要分。
到了 S4，你的构筑已经成型，一次加码的收益可能是前面二十年的总和。
在那一刻点"收手"，需要玩家**主动违背自己整局养成的直觉**。

这就是它必须靠机制赚来、不能靠攻略打卡的原因。

## 4. UI 硬要求：代价必须可见

收手选项**必须显示放弃掉的具体分数**，否则整个机制不成立。

```
┌─────────────────────────────┐
│ 平台给你开了个价，只要你      │
│ 再演一次那个梗。              │
│                             │
│ [ 演。签了 ]         +18.4万 │
│ [ 不演了。回家吃饭 ]      +0 │
│                    放弃 18.4万│
└─────────────────────────────┘
```

`放弃 18.4 万` 这行字是这个机制的全部重量所在。
玩家必须**看着**那个数字点下去。看不见代价，就不是选择，只是一个按钮。

同时：**不给任何暗示**。不加特殊描边、不加音效、不加"（这个选择可能很重要）"。
它看起来就是一个亏钱的蠢选项，因为在游戏的价值体系里它确实是。

## 5. 结局文本规范

**它不是"唯一真诚的声音"，它是唯一没有观众层的文本。**

叙述层通篇都是冷静客观的（`content/authoring.md` §2），
真结局用的是**同一台摄像机**，语气不变。区别在于：
别处的冷静叙述后面跟着一个分数，这里后面什么都没跟。观众层整个消失了。

这比"忽然真诚起来"强得多——忽然真诚是在提示玩家"这段很重要"，
等于变相表扬，正是本节要防的东西。语气完全不变、只是没人再打分，
那个空白自己会说话。

规范极严：

- **平铺直叙的一个普通周二。** 具体、日常、无事发生
- **没有寓意、没有升华、没有点题。** 不出现"其实""原来""终于""重要"这类词
- **不回顾前半生。** 不提修仙、不提爆红、不提赔光。那些事就是没被提起
- **不出现"好日子"这个词。** 结局名叫「稳定的好日子」，文本里绝不能说出来
- 长度 ≤ 200 字。再长就变成散文，就开始抒情了
- **心理活动可以有**，但只能是琐事级（`你想，鸡蛋裂了`），
  不得回顾、不得概括、不得抒情。`authoring.md` §8 的禁用词表
  在心理活动内部同样生效

### 5.1 基调判定问句（BRIEF C7 原文）

> 这段文本读完，玩家想转发的是"笑死"还是"我上了一课"？
> **只有前者合格。**

判定方式：写完后把文本单独拿出来读，如果它像一段"人生感悟"，就是失败的。
它应该像一条平淡到有点好笑的朋友圈。

### 5.2 写作参照

要的：一个人早上煮了两个鸡蛋，其中一个裂了。楼下的狗还是那只狗。
不要的：任何形式的"他终于明白了"。

## 6. 达成后的处理

| 项 | 处理 |
|---|---|
| 收视率 | 照样跌到底 |
| 观众反应 | 照样骂烂尾，节目因"无聊"被砍 |
| 评分 | 显示 `—`，暂无评分 |
| 污点牌 | **一张不移除**，照常在结算页展示 |
| 成就提示 | 无 |
| 图鉴 | 达成后才出现一格，排在其他结局后面，无高亮 |
| 素材奖励 | 与普通结局同档，不额外给 |
| 二次达成 | 无任何区别对待 |

游戏在此**第一次也是唯一一次不给你评价**。

## 7. 反滥用

- 真结局**不参与**任何排行、不计入"最高分"统计
- **不存在任何指向它的人设牌或天赋**（`02-cast.md` §6）。
  如果有一张"通往真结局"的牌，玩家就会去凑牌而不是去做选择
- 达成条件不写进任何游戏内文本、提示、图鉴描述
- 玩家社区一定会攻略出来，这是可接受的：
  **知道条件之后仍然要在 S4 放弃到手的巨额分数**，攻略无法替玩家做那次点击

## 8. 实现检查清单

1. `HOOK` / `HOOKP` 被所有 `escalate` / `restraint` 选项正确读写
2. 每个 `restraint` 选项渲染时实时计算并显示"放弃 N"
3. 高价收手判定用的是**本年所有选项的最高潜在收视**，需在渲染前预算一遍
4. 结算页支持"无评分"形态（`07-settlement.md` §5）
5. 图鉴的真结局槽位在达成前**不存在**，不是隐藏
6. 结局文本走独立渲染分支，不套用常规结局的动效与配色
