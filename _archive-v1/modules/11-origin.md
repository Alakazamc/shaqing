# 模块：开局四项（家庭 / 性别 / 性格 / 特质）

> 上位：`docs/SYSTEM.md` §0 §6、`docs/BRIEF.md` C6（零摩擦）。
> 解锁与分档见 `12-gacha.md`。

## 1. 抽什么

| 项 | 给什么 | 不给什么 |
|---|---|---|
| 家庭 | S1 场景、可达的轨道入口、初始旗标 / 污点 | 属性加成 |
| 性别 | 属性画像、事件池、观众汇率 | 优劣差异 |
| 性格 | 相当于一张开局人设牌，被动倍率，**有正有负** | 纯正面效果 |
| 特质 | 保留原作的天赋三选一 | — |

## 2. 抽，不是选

四项是**抽**出来的，不是挑出来的。

理由：抽的话属性差异就是**方差**而不是**优势**，平衡压力小得多。
玩家不会去挑"最强的性别"，因为挑不了。

| 操作 | 成本 |
|---|---|
| 一键随机抽出四项 | 免费，默认行为 |
| 整体重抽 | 免费 1 次 |
| 继续重抽 | 消耗素材 |

**摩擦控制**：`C6` 要求打开就玩。所以默认是**点一次全部抽好直接进局**，
想调的人再展开面板。深度留给老玩家，新玩家不额外付成本。

## 3. 家庭

决定 S1 的场景、初始旗标、以及**哪些轨道入口在这一局可达**。

例：`山村` 家庭给旗标 `f_shancun`，而修仙轨道入口
（`13-eventlines.md` 里那个下棋的老头）的 `gate` 正是它。
所以家庭是隐秘轨道可发现性的主要旋钮之一（`SYSTEM.md` §5 第 2 条：门槛是状态）。

家庭**不给属性加成**。它给的是可能性，不是强度。

## 4. 性别

性别影响属性和事件。落点是三处，**不是简单的属性加减**。

### 4.1 颜 与 体 不由性别决定

两个性别的 `CHR`（颜）与 `STR`（体）起点用**同一区间**，由家庭与抽卡决定。

已否决的做法：`女 → 颜高体低 / 男 → 体高心低`。
那等于说男的不需要颜值、女的不需要身体。现实上不成立，
机制上则直接砍掉每个性别一半的轨道入口——`颜` 和 `体` 各自都挂着
大量事件与轨道入口（`04-tracks.md` §7）。

**同一属性、同一门槛、不同事件、不同代价。**

```
颜 8
  女 → 开偶像/饭圈轨道。事件池：被消费 / 容貌评价 /
       你不笑的时候他们说你难搞
  男 → 同样开偶像/饭圈轨道。事件池：被说不像干活的 /
       靠脸吃饭的质疑 / 同性排挤

体 8
  女 → 开竞技/体育轨道。事件池：被说不像女孩 / 力气大反而被调侃
  男 → 开竞技/体力轨道。事件池：被默认要扛东西 / 不许示弱
```

### 4.2 三个落点

| 落点 | 说明 |
|---|---|
| 起点微差 | 只在 `SPR` / `STR` 上给很小的偏移，**不在 `CHR` 上做**，幅度小到不构成优劣 |
| **观众汇率** | 同一属性对 `AUD` 的转化率不同，**且双向不对称** |
| 污点风险 | 特定高属性档带来各自特有的污点 |

### 4.3 观众汇率：把双标写进数学，不写进旁白

这个游戏的分数是**收视率**——衡量的是观众有多爱看。
所以最锐利的做法是：**观众对同一属性的反应本身就不一样**，而游戏一个字都不解释。

```
23 岁 · 你在台上赢了

  桥段            22
  × 观众转化      女 1.4  /  男 0.9
```

高颜女性涨观众更快，但污点风险更高；男性走竞技涨观众更快，
而女性走同一条轨道观众不买账。**观众的双标变成一个乘数，
游戏不评论它，只给它定价。**

这正是 `C3`：解构做进数学，不做成旁白。游戏从不说"这不公平"，
它只是把不公平算进收视率——而收视率是这个游戏唯一承认的价值标准。
玩家自己会看出来那意味着什么。

三条护栏必须同时成立：

1. **双向** — 两个性别都有被观众低估的属性，不是单向惩罚
2. **净期望相等** — 用统计断言守，见 §7
3. **零评论** — 不加任何旁白、提示、结算页说明

### 4.4 与跨性别轨道的关系

开局性别是出身设定；跨性别轨道是**局中**的轨道，讲的是"改变"本身。
它中途迁移属性画像，因此改变水位曲线的走法。

轨道入口**不设属性门槛**（`04-tracks.md` §4.1），
且必须实现为带分叉退出的事件线（`13-eventlines.md` §5）。

## 5. 性格

相当于一张开局人设牌：被动倍率，**必须有正有负**。

```js
{ id: 'per_ningjing', name: '拧巴', emoji: '🫥',
  addMult: 0.6, effect: { SPR: -1 },
  desc: '倍率 +0.6，心 -1' }
```

纯正面的性格会让抽卡变成"抽到好性格才开局"，玩家会重抽到手酸，
违反 `C6` 的零摩擦。有代价才能让每一次抽出的结果都可玩。

## 6. 特质

保留原作的**天赋三选一**（`explore/ref-lifeRestart.md` §5：抄）。
这是四项里唯一让玩家真正做选择的一项，放在最后，作为进局前的最后一次决策。

## 7. 好出身天然不是优势

这一条不是我硬加的平衡，是现有公式自己长出来的。

振幅算的是水位的 **log 比值**，且水位被 clamp 在 `[1, 100]`（`SYSTEM.md` §3.1）：

```
富二代开局   W ≈ 71  →  往上只剩 log₁₀(100/71) ≈ 0.15 个数量级
普通出身     W ≈ 35  →  往上有   log₁₀(100/35) ≈ 0.46 个数量级
穷出身开局   W ≈ 15  →  往上有   log₁₀(100/15) ≈ 0.82 个数量级
```

而单段幅度上限是 `0.8`。所以**富二代根本做不出"暴富"这条弧线**，
他往上的空间连半段满幅都不够，只能走跌落。

> **修订记录**：初版写的是 `W ≈ 60 → 0.22` 与 `W ≈ 8 → 1.10`。
> 那组数字基于 `01-scoring.md` §4.1 的旧水位公式，而旧公式上界只有 38，
> `W = 60` 不可达。公式已修正为归一化形式，本节数字按新公式重算。

好出身不是变强，是**把一条路堵死了、逼你走另一条**。

## 8. 平衡断言

光靠设计原则守不住"不同 ≠ 更强"。补进 `09-vertical-slice.md` §5：

> - 1000 局随机策略按性别分组，两组评分**中位数之差 ≤ 0.3**。
>   超出则调事件池桥段基数与观众汇率，**不改公式结构**。
> - 调参报告必须逐属性输出"两个性别下的平均收视贡献"，
>   不强制相等，但**必须可见**。

第二条防的是"总分平了但内部废掉一半属性"：
总分持平、可是女性的 `STR` 完全无用，那仍然是设计失败。

## 9. 分档与解锁

家庭 / 性格 / 特质各分 T1–T3，由抽卡解锁（`12-gacha.md`）。

**T3 不是更强，是更荒谬：**

| 档 | 家庭示例 |
|---|---|
| T1 | 普通工人家庭、小镇个体户、山村 |
| T2 | 全家考公上岸、父母是同一家工厂的、单亲加一个不联系的哥哥 |
| T3 | 你出生在一个所有人都是网红的家庭 / 你爸在你三岁时进了一个组织 |

T3 更容易触发极端事件链，但也**更难做出高振幅**——起点已经很离谱，
反差空间被压缩（同 §7 的机制）。

**"高级" = 更多可能性，不是更高上限。** 这样每局仍然在同一套公式下公平，
`SYSTEM.md` §6 "不解锁数值强化"的原则不被破坏。

## 10. 一致性检查

补进 `content/README.md` §5：

1. 每个家庭项的旗标都被至少一条轨道入口或事件的 `include` 引用
   （否则是死内容）
2. 每个性格项**同时**有正向字段与负向字段
3. 性别相关的观众汇率表对两个性别都非空，且**至少各有一项 < 1.0**
   （保证双向不对称）
4. T2 / T3 项都有对应的抽卡池条目
5. 无任何轨道入口的 `include` 引用 `SEX`
   （轨道门槛必须性别中性，`04-tracks.md` §7）
