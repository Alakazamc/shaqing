## 0. 配额上限：先说限制，再说内容

超自然题材必须受配额约束，否则本作会从"荒诞的普通人生"滑成奇幻游戏。

`BRIEF.md` §1 写明本作取的是**现实共鸣 + 黑色幽默**
——"笑完之后是这不就是我"。这条共鸣是超自然内容稀释不起的。

| 约束 | 值 |
|---|---|
| 异常轨道占总轨道数 | **≤ 1/3**（首发 23 条 → 异常最多 7 条） |
| S1–S2 可触达的异常轨道 | **≤ 1 条**（童年少年期必须是写实的） |
| 一局最多进入的异常轨道 | **1 条**（进了一条就锁其余） |
| 异常事件占单局事件数 | **≤ 25%** |

最后一条是硬底线：**即使走了异常轨道，一局里四分之三的事件仍然是普通生活**。
房租、体检、你妈打电话——这些不能因为你成了吸血鬼就消失。
反过来说，正是它们让异常显得异常。

### 1.1 收容（SCP 式）

**笑点来自并置**：世界可能要毁灭，但你得先把三份表交上去。

- 职业阶梯：`临时工 → 二级研究员 → 站点主管`（`17-jobs.md`）
- 每年的 `wear` 是 `SPR`，不是 `STR`——这份工作磨的是精神
- 特有污点 `📄失效的保密协议`
- 文案禁止解释异常是什么。**只写流程、编号、签字栏**

register 参照（只示范语气）：

```
✓  编号 1174 的物件今天需要三次投喂。表格 C 要求你签字确认它"情绪稳定"。
✗  你面对着无法理解的恐怖存在。
```

### 1.2 后室（Backrooms 式）

**机制独特点：`AUD` 增长被切断。** 没人看得见你，收视放大系数停在原地。

这让它成为全局最难得分的轨道，而这正是它的卖点：
玩家会为了图鉴去走它，然后发现自己的收视被冻结——
"没有观众"在这个游戏里是最重的惩罚，而它同时是最贴切的表达。

- 空间失去意义 → 压缩推进被禁用（每一年都必须点，因为"下一年"不再自动到来）
- 特有污点 `🚪走错的门`

### 1.3 夜里的人（吸血鬼）

**明确的取舍，不是纯增益**：

| 得到 | 代价 |
|---|---|
| 寿命上限 `+120` | **不能被拍到**：`AUD` 上限锁在 30 |
| `STR` 上限 `+10` | 白天事件池全部关闭（可用事件减半） |

`AUD` 上限锁死意味着 `A = AUD/10` 最多 3.0，而普通轨道后期能到 7+。
所以吸血鬼的分数只能靠**极长的人生累积**，不能靠爆发。
这是一条完全不同的得分曲线，值得单独存在。

`C4` 处理：不用"吸血鬼"这个词。轨道名是 `夜里的人`，
文案只写作息、体温、别人的反应。

### 1.4 披风（超级英雄）

**它是全作最贴主题的一条轨道**，因为超级英雄本质就是在为观众表演。

- 每次使用能力：`AUD +N`，同时 `HOOK +2`
- 不使用能力：什么都不会发生（能力不产生收视）
- 于是它把 `HOOK`（戏瘾）轴直接摆到台面上：**你越有用，越戒不掉被看**
- 真结局（`08-true-ending.md`）在这条轨道上最锋利：
  收手意味着"有能力却不出手"，代价可见得刺眼

特有 legend 牌 `🦸只在没人看见时出手`：`AUD` 增长归零，但 `xMult ×3.0`。
这张牌是 C3 的又一个基准例——它把"没人看见"变成了数值优势。

### 1.5 延寿型轨道：魔法与科幻

`mofa` 的延寿来自事件线终点，而不是轨道入口：走主链得到一张更强、代价更重的牌，
走分叉得到一张较弱但更容易与普通生活并存的牌。`kehuan` 是隐藏的科幻题材轨道，
不增加新的异常规则，只用低温、样本和回访写“把未来存起来”的现实代价。

两条线都遵守：延寿牌必须在终点选项中授予；寿命增加与倍率或属性损耗同时出现；
事件线之外仍会继续抽到房租、工作和家庭事件。延寿不是逃离生活，只是把结局往后推。

## 2. 为什么时间循环值得单独做机制

其余异常轨道是**内容**，时间循环是**机制**。

它和现有计分系统咬合得非常紧，几乎是白捡的：

| 现有机制 | 时间循环下的含义 |
|---|---|
| `F = 0.6^n` 疲劳系数 | **观众在看重播。** 同一年播第二次，收视直接 ×0.6 |
| 振幅需要多段单调曲线 | 循环期间水位不动 → 不产生新段 → **振幅冻结** |
| 收视率 = 观众有多爱看 | 重播没人看。这不是隐喻，是字面意思 |

**结论：循环本身几乎不得分。** 而这正是它成立的原因——
玩家必须想办法出去，而出去的唯一方法是做一件之前没做过的事。

疲劳系数原本是 §2 的反刷分闸门，在这里变成了叙事机制。
同一台数学，两种用途，不需要新公式。

## 3. 时间循环机制

### 3.1 状态

```js
LOOP: {
  year: 27,              // 被锁住的那一年
  count: 3,              // 已经循环几次
  seen: ['a', 'b'],      // 这一年里做过的选项 id
  lineId: 'el_qiyue'
}
```

### 3.2 规则

| 规则 | 说明 |
|---|---|
| 年龄不推进 | `age` 锁在 `LOOP.year` |
| 每轮播同一批事件 | 但**选项逐轮减少**：做过的选项标记为"你试过了" |
| 收视 | 每轮 `F` 继续衰减（第 4 轮已经 ×0.216） |
| 水位 | 不记入 `WLOG`——循环不产生振幅段 |
| **破环** | 选中带 `breaks: true` 的选项 |
| 普通选项 | 选过即消耗，之后不再出现（"这个试过了"） |
| 循环上限 | **6 轮**。到上限强制破环并给污点 `🔁那年七月` |

> **修订**：初版写作"破环 = 选中 `seen` 里没有的选项"。这是错的——
> 每次选择都会进 `seen`，那么第一次选就破环了，循环根本不成立。
> 改为显式的 `breaks` 标记：**大部分选项是"试了但没用"，只有一个是出口。**

"选项逐轮减少"是关键设计：它让玩家**看得见自己在重复**，
而不是靠一行提示告诉他。普通选项被消耗完之后，
屏幕上只剩那个 `breaks` 选项——而它通常是玩家一开始不愿意选的那个。

出口选项**不设额外门槛**（不需要 `count >= N`）：
玩家第一轮就可以选它。设计意图是让"早点认了"成为一个真实的选项，
只是它的破环收益随轮数递增，所以贪心的玩家会想多熬几轮。

### 3.3 破环的收益

循环不得分，破环一次性给足：

```
破环桥段 = 基础 60 + 12 × 循环轮数
```

第 6 轮破环 = `60 + 72 = 132` 桥段，是全局最高的单次桥段值。

叙事上说得通：**观众忍了六集重播，第七集终于有进展。**
数学上也说得通：它补偿了循环期间被疲劳吃掉的收视。

### 3.4 与真结局的关系

时间循环里**不允许出现 `restraint` 选项**。

理由：真结局要求"在最贪的时刻主动放弃到手的分数"（`08-true-ending.md` §3），
而循环里本来就没有分可放弃。在这里放收手选项会让 C7 的判定变得廉价。

破环那一下可以是 `escalate`，但不能是 `restraint`。

### 3.5 反滥用

- 一局最多进入 **1 次**时间循环
- 循环期间 `AUD` 不增长（重播不涨观众）
- 循环期间的事件不计入 `EVT`，避免把回响事件的门槛污染掉
- `LOOP` 状态必须能 JSON 往返（纯数据，requirements §4）

## 4. 一致性检查

补进 `content/README.md` §5.1：

1. 异常轨道数 ≤ 总轨道数的 1/3
2. `S1`/`S2` 可触达的异常轨道入口 ≤ 1 条
3. 每条异常轨道的入口 `include` 不引用 `SEX`
4. 时间循环事件线的任一节点**不得含 `restraint` 选项**
5. 时间循环的选项总数 ≥ 上限轮数（否则玩家会卡在没有新选项可选）
6. `houshi` 轨道的事件不得给 `AUD` 正增益（该轨道的定义就是观众被切断）
7. `xixie` 轨道必须同时声明 `lifespan` 增益与 `audCap` 上限
   （不许只给好处不给代价）
