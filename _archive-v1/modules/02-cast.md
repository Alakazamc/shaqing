# 模块：人设牌与污点牌

> 上位：`docs/BRIEF.md` §3（映射不得改动）、`docs/SYSTEM.md` §0 §2。

## 1. 为什么人设牌能干净地映射小丑牌

小丑牌里的小丑**是被动的**：你不操作它们，它们只是站在那里改写倍率；
主动部分是出牌。所以映射是干净的，不是缝合：

| 小丑牌 | 本作 | 玩家操作 |
|---|---|---|
| 小丑（Joker） | **人设牌** | 无。只能通过事件选择获得，永不手动打出 |
| 出一手牌 | **过完一年** | 一次点击 |
| Boss 盲注 | **季末结算** | 无 |
| 商店 | **事件选项** | 点选项即是"购买" |

结果：零手牌管理，但连锁爆炸的手感全在（C1 与"小丑牌爽感"同时成立）。

## 2. 数据结构

```js
{
  id: 'cast_chouxiang',
  name: '抽象怪',
  emoji: '🤡',
  rarity: 'rare',              // common | rare | epic | legend
  track: 'chouxiang',          // 所属轨道，null 表示通用
  tags: ['网络', '失控'],       // 取自 content/tags.js 固定枚举
  desc: '每张污点牌让本年桥段 +2',
  // 三种效果字段，可同时存在
  addDrama: { per: 'SCAR', value: 2 },   // 条件式加值
  addMult:  0.8,
  xMult:    null,
  // 可选：被事件授予时立即增加寿命上限
  lifespan: null,
  maxLv: 3,
}
```

`addDrama` 的 `per` 支持：`SCAR`（污点数）、`CAST`（人设数）、
`TRACKLV`（主导轨道深度）、`AUD10`（每 10 点观众）、固定值。

**升级**：同名牌再次获得时 `lv +1`（上限 `maxLv`），效果按 `lv` 线性放大。
这样"重复获得"不浪费，避免玩家在选项前算"我已经有这张了"。

## 3. 稀有度与倍率上限

| 稀有度 | `addMult` | `xMult` | 出现方式 |
|---|---|---|---|
| common | +0.2 – +0.4 | — | 常规事件选项 |
| rare | +0.5 – +0.9 | — | 转折事件选项 |
| epic | +1.0 – +1.5 | ×1.5 – ×2.0 | 轨道深度 ≥3 才解锁的事件 |
| legend | — | ×2.5 – ×3.0 | 隐秘轨道终点 / 图鉴解锁 |

硬约束（来自 `01-scoring.md` §3.2）：
**单张牌不得让 `M` 超过 4.0；`M > 8` 必须是至少 3 张牌咬合的结果。**

## 4. 污点牌

污点牌是 C3 的主要载体。

```js
{
  id: 'scar_zhushui',
  name: '注水',
  emoji: '💧',
  desc: '全局倍率 ×0.85（可叠加）',
  mult: 0.85,
  removable: false,     // 永远是 false，这是设计红线
  tags: ['烂尾'],
}
```

**污点永不移除。** 不提供任何洗白、赎回、治疗机制。
玩家会主动去搜"怎么去掉污点"，找不到——这本身是态度表达。

污点来源：季末腰斩、加码失败、部分选项的必然代价。

### 4.1 污点如何反转成优势（C3 审查基准）

BRIEF C3 给的基准例必须真实存在：

| 牌 | 效果 | 后果 |
|---|---|---|
| 🧊 `反社会人格`（天赋，legend） | 每张污点牌 `addMult +1.0` | 3 张污点 → `+3.0` 倍率 |
| 🩹 `破罐破摔`（cast, epic） | 污点数 ≥5 时 `xMult ×2.0` | 鼓励主动堆污点 |
| 💧 `注水`（scar） | `M × 0.85` | 在上面两张牌下**净收益为正** |

于是"活成一团糟"在数值上是最优解，**被腰斩反而是构筑燃料**。
游戏用自己的计分公式否定了自己设定的失败条件。

审查标准（每次新增机制都要过）：
> 这条机制能否让"堕落 / 失败 / 荒诞"在某种构筑下变成数值优势？
> 不能，就说明它不够本作。

## 5. 咬合设计原则

人设牌之间必须**互相咬合**，否则就只是一堆独立加数。三种咬合模式：

| 模式 | 例 |
|---|---|
| 计数咬合 | `破罐破摔` 数污点；`社交恐怖分子` 数人设总数 |
| 轨道咬合 | `筑基` 让所有修仙牌 `addMult` 翻倍 |
| 反义咬合 | `双重人格`：持有两条不同轨道的 epic 牌时 `xMult ×2.5` |

反义咬合是给"半途而废"留的唯一出路：一般情况下换轨道会被 `Com` 惩罚，
但特定牌把"人设分裂"本身变成卖点。这保证了构筑空间不是单一最优路径。

## 6. 与真结局的关系

人设牌**不参与**真结局判定。真结局只看 `HOOK` / `HOOKP`（见 `08-true-ending.md`）。

原因：如果存在一张"通往真结局"的牌，玩家就会去凑牌而不是去做选择，
C7 要求的"在最贪的时刻主动放弃到手的分数"就被绕开了。
真结局必须靠**反复放弃**赚来，不能靠构筑拿到。

同理，达成真结局时**一张污点牌都不移除**——你只是不再表演了，不是被洗白了。
