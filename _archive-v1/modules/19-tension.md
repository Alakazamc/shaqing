# 模块：分数的用处（张力循环）

> 上位：`docs/BRIEF.md` §1（取小丑牌的什么）、`docs/SYSTEM.md` §2 §4。
> 本模块修的是纵切片暴露的核心缺陷：**分数算出来了，但玩家感觉不到它有用。**

## 0. 缺陷诊断

BRIEF §1 写明要取小丑牌的"被动构筑 → 连锁 → 数字爆炸"。
纵切片把**计分公式**抄过来了，却漏掉了让分数有用的那套结构。

对照参考资料（均已改写以符合授权要求）：

| 参考游戏的做法 | 来源 | 本作初版 |
|---|---|---|
| 玩家对抗**递增的分数目标**，目标**始终可见**，随时知道差多少 | Balatro 入门指南 | ✗ 续订线只在季末出现 |
| 分数与货币**是两套**；货币用来买小丑，且留存有利息，"花光"是真决策 | Balatro 经济讨论 | ✗ 收视与素材合一，局内无可花之物 |
| 每场战斗后**三选一**加牌，分数/表现越好奖励越好 | Slay the Spire 评述 | ✗ 完全没有 |
| 要用**还没建好的牌组**去赢，构筑与考核同时进行 | StS 策略文章 | 部分成立（季末阈值） |

结论：缺的不是公式，是**反馈回路**。分数没有可见的目标、没有花处、没有即时兑现。

## 1. 三条修正

### 1.1 续订线常驻可见

顶栏永久显示 `本季收视 / 续订线` 进度条，每一年的收视都在推动它。

```
S3 当红    ▓▓▓▓▓▓▓░░░░░  1840 / 700 · 已达标 2.6×    👀 38
```

要点：

- **进入季首就告知本季目标**，不是季末才揭晓
- 达标后进度条不消失，改显示**超额倍数**——这是奖励档位的预告
- 超额倍数是玩家"再冒一次险"的唯一理由，必须一直在视野里

这一条成本最低、收益最大：它把每年的分数从"记在账上"变成"看得见地推进"。

### 1.2 季末三选一（分数的直接兑现）

达标后不再是一句"续订"就过场，而是**从 3 个奖励里选 1 个**。

**奖励档位由本季超额倍数决定**，这就是分数的用处：

| 超额 | 档位 | 奖励池 |
|---|---|---|
| 1.0 – 1.5× | 普通 | common / rare |
| 1.5 – 2.0× | 稀有 | rare / epic |
| ≥ 2.0× | 史诗（同时加更） | epic / legend |

奖励类型（三选一时从中抽 3 个不同类型）：

| 类型 | 内容 |
|---|---|
| 人设牌 | 直接获得一张（档位对应稀有度） |
| 观众 | `AUD +N`，N 随档位 |
| 加更 | 本季追加 2–4 年（更多脉冲＝更多分） |
| 职业跳级 | 直接晋升一个 `tier`（`17-jobs.md`） |
| 属性 | 单项 +2 – +4 |
| **污点交易** | 主动吃一张污点，换一张高一档的人设牌 |

最后一条是 C3 的载体：**它让"主动把自己搞脏"成为一个有数值收益的选项**，
而且在吃污点的构筑下净收益为正。

### 1.3 不引入新货币

考虑过加"话题度"作为局内货币，**否决**。

理由：`收视` 本身就是季内累积、季末清零的量，它已经具备"额度"的性质。
再加一层货币会违反 C1 的极简原则，且玩家要同时盯两个数。

**超额倍数就是货币。** 花它的地方是季末三选一的档位。

## 2. 改动后的完整张力循环

```
季首：告知本季续订线
  ↓
每年：事件 → 选择 → 收视结算 → 进度条推进（目标一直可见）
  ↓
接近季末：进度条告诉你差多少
  → 不够 → 必须冒险加码
  → 已够 → 要不要再拼一档奖励？（这是"见好就收"的第一层张力）
  ↓
季末：达标 → 按超额档位三选一 → 构筑成长
      未达标 → 腰斩 → 注水续命（污点 = 某些构筑的燃料）
  ↓
下季：续订线更高
```

**"要不要再拼一档"这个决策是真结局机制的预演**：
真结局要求在最贪的时刻放弃到手的分数（`08-true-ending.md`），
而季末三选一让玩家在整局中反复练习同一种取舍。
这不是巧合，是把 C7 的核心张力下沉到每一季。

## 3. 与既有正典的关系

- 不改年度公式、不改三乘数、不改评分映射（`14-content-api.md` §5.2 的四样封闭项）
- 季末判定仍是 `SYSTEM.md` §4 的加更/续订/腰斩三分支，
  只是在"加更"与"续订"之后**插入一次三选一**
- 腰斩分支不变

## 4. 一致性检查

补进 `content/README.md` §5.1：

1. 每个季末奖励条目有合法 `rarity`（`18-rarity.md`）与 `type`
2. 每个档位的奖励池条目数 ≥ 5（保证三选一不重复）
3. `污点交易` 类奖励必须同时指定 `scar` 与 `cast`，且 `cast` 稀有度高一档
4. 奖励里**不得出现移除污点**的类型（`02-cast.md` §4 红线）
5. 三选一的三个选项 `type` 互不相同
