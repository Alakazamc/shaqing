# 设计纲领（BRIEF）

> 这是所有设计文档的**上位约束**。任何模块设计与后续代码若与本文冲突，以本文为准。
> 本文只规定"必须成立的东西"，不规定实现细节。

项目代号：**badhand**（暂名，源自"一手烂牌"）
目标平台：纯静态网页，手机竖屏优先，打开即玩、无需注册。

### C8 — 零美术资产，emoji 即 UI（资源约束）
不生成任何图片素材。**emoji 是自带跨平台语义的现成美术**：人设牌用 emoji 作图标，
分享卡用 Canvas 绘制 emoji + 文字排版，全程无 png/svg/字体资产。

技术选型：**Vue 3 全局构建（本地 vendored，无构建步骤）**。
`index.html` 双击即跑，不需要 npm install、不需要打包器、不依赖网络。
视觉风格靠 CSS（排版、留白、色板、动效）撑起来，不靠贴图。

## 0. 一句话

一个把人生当牌局来结算的网页游戏：你只能点击，但你的人生会以离谱的方式数值爆炸，
而游戏给你的分数，衡量的是**你的人生作为一个故事有多好看**——不是你过得有多好，也不是你过得有多惨。

## 1. 三个来源，各取什么

| 来源 | 取什么 | 明确不取什么 |
|---|---|---|
| 人生重开模拟器 | 文本事件的密度与质感；选择影响后续选项；奇幻/科幻/亚文化题材混入写实底色；肉鸽 meta 进度 | 纯随机看戏的被动感（原作玩家实际决策极少） |
| 小丑牌 Balatro | **被动构筑 → 连锁 → 数字爆炸**的爽感；构筑转向的决策感；"这套组合能打出多少"的炫耀欲 | 手牌管理、弃牌、卡牌操作等一切复杂输入 |
| 杀戮尖塔 | 分支路线的取舍；每层前可预览的路线选择 | 战斗回合制、能量/耗牌等操作层 |

**弃用打砖块（cctan）**：BBTAN 的唯一决策是瞄准角度，无法承载"选择→后果→新选择"的语义，
与叙事拼接只能是贴皮换壳。已确认放弃。

## 2. 不可违背的硬约束

### C1 — 交互只有点击
全程只有两种操作：**「过完这一年」** 和 **「从 2-3 个选项里点一个」**。
没有拖拽、没有手牌、没有数值分配、没有瞄准。零学习成本，看别人截图就能懂怎么玩。
深度全部放在**内容与数值**，不放在输入复杂度。

### C2 — 计分衡量戏剧性，不衡量惨或成功
"事业有成家庭美满"接近零分，**"故意把自己搞得很惨"也必须接近零分**。
否则玩家只是把"奋斗最优解"换成"摆烂最优解"，一样无聊。
评分三乘数（细节见计分模块）：

- **振幅** — 有没有大起大落。一路平顺和一路烂到底都是单调曲线，都不得分。暴富之后赔光才炸。
- **贯彻** — 一个人设走到荒谬的极致。半途而废的修仙者不如走火入炉的。
- **反讽** — 铺垫与收尾对上。死法与天赋互相呼应时触发额外倍率。

游戏否定的是**乏味**，不是成功，也不是失败。

### C3 — 解构做进数学，不做成旁白
不靠嘲讽解说来表达态度，靠**规则本身自我否定**。
基准例（必须存在同类机制）：污点牌不可移除，但天赋「反社会人格」让每张污点牌 +1 倍率
——于是"活成一团糟"在数值上是最优解，游戏用自己的计分公式否定自己的道德框架。

审查标准：一条机制若不能让"堕落 / 失败 / 荒诞"在某种构筑下变成数值优势，它就不够本作。

### C4 — 亚文化与奇幻要素隐秘化
表面必须是写实的普通人生。修仙、魔法、电竞、偶像、说唱、富二代、彩票暴富、
地雷系、跨性别、以及药物致死这类题材，都是**被玩家发现的**，不在开局展示、不写进教程。
"等等，这游戏能修仙？"这句话本身就是转发理由。

敏感题材（药物、自毁、性别议题）一律用**含蓄、克制、不猎奇**的语言处理：
写状态与后果，不写过程与方法；不浪漫化，也不说教。

### C5 — 梗要圈层化，避免老人味
少用已被官媒和 HR 用烂的泛梗（内卷、躺平、社死这一类）——写进去像市场部文案，不像群友。
**以亚文化圈层内部梗和新梗为主**，并且梗跟随玩家所处轨道投放：
二次元轨道吃二次元梗，鼠鼠轨道吃鼠鼠梗，电竞轨道吃电竞梗。
窄梗在圈内的转发率高于泛梗，而截图正是在圈内传播的——**圈子梗是传播设计的一部分，不是缺陷**。

工程约束：所有梗集中在 `docs/content/lexicon.md`，每条标注圈层与**过期风险等级**；
高风险梗只出现在可替换的文案槽位，**绝不写进机制名称或主干逻辑**。

### C6 — 传播是一等需求
不是做完游戏再加分享按钮。结算页即主界面，每局必须产出**一件值得截图的畸形作品**。
所有随机由种子驱动，链接可带 seed 让别人重开同一条命。

## 3. 核心结构（已定骨架）

映射关系是本作成立的基础，**不得改动**：

```
小丑牌的「小丑」   →  人设牌（被动，永不手动打出，互相咬合放大倍率）
小丑牌的「出一手牌」 →  过完一年（一次点击；年份事件产出基础分）
小丑牌的「Boss 盲注」→  章节结算（童年/少年/青年…每章末清算）
小丑牌的「商店」    →  事件选项（选择即构筑，没有独立购买界面）
```

要点：
- 人设牌**只能通过事件选择获得**，玩家永远不"打出"它们，因此不产生任何操作负担。
- 一年 = 一次点击 = 一次结算脉冲，数字在这一刻跳动、连锁、爆炸。
- 章节结算决定：能否活到下一章、解锁哪条隐秘轨道、以及最终评级。

## 4. 立项时未决、需要设计文档回答的问题

1. 章节结算若不达标会怎样？直接死亡（roguelike 失败）还是转入更荒诞的低分支？
2. 人生"长度"是固定 0-N 岁，还是由构筑决定（有的人设活不过 20，有的活到 200）？
3. 振幅如何量化才不被玩家用"先自残再暴富"的固定套路刷爆？
4. 隐秘轨道的入口如何做到既隐蔽又不至于让玩家永远发现不了？
5. meta 进度解锁什么？（新天赋池？新轨道？还是仅仅是图鉴收集）
6. 一局时长目标是多少？（传播要求短，构筑深度要求长，需要取一个具体数）

## 5. 基调参考坐标

- 想要的：《人生重开模拟器》的荒诞感 + 早期贴吧/小组的自嘲 + 抽象话的失控感
- 不要的：正能量、励志、感动、"其实平凡也很好"这类和解式收尾
- 也不要的：为了黑暗而黑暗、无差别虐主角、猎奇苦难展览

**唯一例外（C7，见下）**：隐藏真结局允许真诚，但必须靠机制赚来，且游戏不得表扬玩家。

### C7 — 隐藏真结局：稳定的好日子
最高层级的隐藏结局不是最高分，而是**退出计分**。

- 它**不能**靠"一路选安稳"达成——那是乏味，按 C2 必须接近零分。
  达成前提是**先真的经历过大起大落**，然后在收益最高的时刻**连续拒绝加码**，
  每次拒绝都要放弃已经到手的分数。见好就收在 roguelike 里是最难的操作。
- 达成后收视率照样跌到底，观众照样骂烂尾，节目照样因"无聊"被砍。
- 结局文本是全游戏唯一一段真诚的文字：平铺直叙的一个普通周二，
  **没有寓意、没有升华、没有点题**。污点牌一张都不移除——你只是不再表演了。
- 游戏在此**第一次也是唯一一次不给你评价**。不是"平凡真好"，是评分框架自己脱落了。
- 图鉴里它在达成前显示为空槽，游戏从不暗示它是"最好的"结局。

设计意图：第一层解构成功叙事，第二层把玩世不恭本身也解构掉
——"活成一场精彩车祸"同样是在为观众表演，同样是笼子。真结局是从笼子里走出去。

**基调判定问句**：这段文本读完，玩家想转发的是"笑死"还是"我上了一课"？
只有前者合格。
