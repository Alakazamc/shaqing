# 文案写作规范

> 上位：`docs/BRIEF.md` §5（基调参考坐标）、C3 C4 C5 C7。
> 事件文案的质量是整个项目最难的部分，也是唯一无法用工程手段替代的部分。

## 1. 基调坐标

| 要的 | 不要的 |
|---|---|
| 《人生重开模拟器》的荒诞感 | 正能量、励志、感动 |
| 早期贴吧 / 小组的自嘲 | "其实平凡也很好"这类和解式收尾 |
| 抽象话的失控感 | 为了黑暗而黑暗、无差别虐主角 |
| 具体的、有质感的细节 | 猎奇苦难展览 |

## 1.5 三个声音：叙述层、观众层、信号层

这是全部写作规范里最重要的一条结构约束。

| 层 | 包含 | 声音 | 是否评价 |
|---|---|---|---|
| **叙述层** | 事件正文、选项文案、死法、结局文本 | 摄像机 | **零评价** |
| **观众层** | 结算页短评、收视数字、标签、腰斩通知、加更通知 | 刻薄、有观点 | 评价个不停 |
| **信号层** | 变色、色差、文字破碎、抖动、粒子 | **没有观点，只会故障** | 不评价，只是坏掉 |

游戏的态度**全部住在观众层和数学里**，叙述层一句不表态。

这比"通篇冷静"更狠：它让评判显得是**别人**在做，
而那个别人正是这个游戏从头到尾在解构的对象。
所以短评写得刻薄（`modules/07-settlement.md` §3）与叙述层的零评价**不冲突**，
它们是不同的声音。

### 1.5.1 信号层为什么不算叙述者表态

"文字突然变红"严格说是叙述者在表态。但归属可以不同：
**不是叙述者害怕了，是播出信号出问题了。**

框架是"你的人生是一部剧"，所以恐怖表现为**信号劣化**，
不表现为叙述者的情绪。观众正在看的那台电视坏了。

于是恐怖事件的**文字本身仍然冷静客观**：

```
✓  房东说这间以前也租过人。押一付三，他没说付几个月。
✗  你感到一阵寒意，这房子有些不对劲。
```

字是冷的，信号在抖。**§8 的禁用词表因此继续全额生效**，
不需要为恐怖题材开任何例外。

视觉规范见 `modules/15-signal-fx.md`。

## 2. 叙述层七条硬规则 + 一条例外

总纲：**客观、冷静、不含价值说教，可以带一点冷幽默。**

规则 §2.1–§2.7 是硬规则，§2.8 是例外（角色台词与心理活动），
§2.9 是长度上限。

### 2.1 写具体，不写概括

```
✗  你的事业遭遇了重大挫折，心情十分低落。
✓  甲方把你的方案发到群里，说"大家看看这个"。
```

概括是零信息量的。具体细节才能让玩家在"这不就是我"和"笑死"之间来回。
**每条事件至少有一个具体到有点多余的细节。**

### 2.2 摄像机视角，不定性情绪

只写可观察的：动作、对话、数字、物件。

```
✗  这让你很受伤。
✓  你把外卖吃完了，盒子在桌上放了三天。
```

### 2.3 笑点来自并置，不来自俏皮话

冷幽默从两个事实挨在一起产生，不从形容词或吐槽产生。

```
✗  真是倒了八辈子霉。
✓  医生说没什么大事。挂号费 300。
```

### 2.4 不给因果，把事按顺序摆着

```
✗  因为长期熬夜，你的身体垮了。
✓  你连着上了四个月。体检报告上有三个箭头。
```

### 2.5 数字是最冷的载体

具体数字自带荒诞，不需要评论。

```
✓  在线人数：1。是你妈。
✓  那条有 4 万赞。你妈问你什么时候找个正经工作。
```

### 2.6 不解释笑点，不点题

```
✗  你终于明白，人生就像一场没有观众的直播。
✓  在线人数：1。是你妈。
```

C3 已定：解构做进数学，不做成旁白。文案的任务是把事情说出来，
不是告诉玩家该怎么想。

### 2.7 短句，句末不加语气助词

「了吧」「呢」「啊」会把冷变热。

### 2.8 例外：角色可以随便评价

叙述者不表态，但**角色想说什么都行**——你妈、班主任、NPC 的判断
本身就是可观察事实的一部分。

```
✓  你把邻居家的猫从树上抱下来，猫抓了你一下。你妈说这叫好人没好报。
```

叙述部分零评价，评价交给"你妈说"。

**玩家的心理活动同属此例外。** "你想：……"可以写，
内心台词与角色对白同级，都是可引述的内容。

```
✓  你想，反正也没人注意。第二天有三个人注意到了。
✗  你想，原来这才是最重要的事。
```

两条的区别是：前者是一句想法，后者是拿内心独白点题。
**§8 的禁用词表在心理活动内部同样生效**，
尤其"其实 / 原来 / 终于 / 明白"这一组。

### 2.9 长度上限

| 位置 | 上限 |
|---|---|
| decision 事件正文 | **140 字** |
| flavor 事件正文 | **90 字** |
| echo 回响事件正文 | **140 字** |
| 场景节拍 | **60 字** |
| 选项文案 | **20 字** |
| 短评 | 30 字 |
| 结局文本 | 200 字 |
| 真结局文本 | 200 字（且见 §5）|

> **修订记录**：初版把事件正文卡在 60 字、节拍 30 字。
> 纵切片实测的结论是**过短**：一屏读完的约束满足了，
> 但事件读起来是碎片，无法承载前情与后果，整条命看不出连贯性。
>
> 传播要求的是"截图里读得完"，不是"短"——**过短反而没有可转发的内容**。
> 手机竖屏一屏能读完 140 字（约 5 行），上限因此放宽到 140。

## 2.10 连贯性：文本必须指涉前情

这是与"写得好不好"平级的**结构要求**，不是加分项。

一条命读起来像一串碎片，通常不是文案不用心，而是事件之间没有引用关系。
DSL 早就支持，只是内容层没用：

```
EVT?["e_s2_d02"]          你当年撕了那张表格
JOB=["job_liushui"]       你现在在流水线上
FLAG?["f_fuqin_bing"]     你爸的身体
NPCKNOWN?["npc_qishou"]   那个下棋的老头
```

三条硬要求（细则见 `modules/17-jobs.md` §3）：

1. **每季至少 4 条事件的 `include` 引用前情**
2. **每季 1–2 条 `kind: 'echo'` 回响事件**，专门指涉多年前的事
3. **职业必须被文本指涉**：同一情境在不同职业下写不同文案，
   不做通用文案 + 占位符替换（那读起来仍然是模板）

> 反面例子（初版的通病）：
> `你在直播里说了句话。切片正在传播。`
> ——它可以出现在任何一条命里，因此不属于任何一条命。
>
> 改法：让它指涉你的职业与前情。
> `你在流水线上干了六年，第一次开播。说了句什么，切片正在传播。
>  评论里有人问你是不是XX厂的。`

## 3. 选项写作

### 3.1 加码 / 收手必须成对

每个 `decision` 事件里，若有 `restraint` 选项，就必须有 `escalate` 选项
（`content/README.md` §5 检查 8）。因为收手选项要显示"放弃了多少分",
没有加码选项就无从计算。

### 3.2 选项不得自我标注

```
✗  [ 冒险一搏（高风险高回报）]
✗  [ 【修仙】拜师学道 ]
✓  [ 跟着那个老头去后山 ]
```

C4 已定：隐秘轨道入口在文本上必须读起来像普通选项。
不打标签、不给提示、不加括号说明。

### 3.3 收手选项必须写得像蠢选项

真结局的收手选项在游戏价值体系里确实是亏的，文案要坦然承认这一点：

```
[ 演。签了 ]              +18.4万
[ 不演了。回家吃饭 ]           +0
                     放弃 18.4万
```

`回家吃饭` 而不是 `坚守自我`。后者是在暗示这是正确答案，直接违反 C7。

## 4. 敏感题材（C4）

适用于 `dilei` / `kuaxingbie` / `yaowu` 三条轨道及所有自毁类事件。

| 规则 | 说明 |
|---|---|
| 写状态与后果，不写过程与方法 | 不出现物质名、剂量、手法、具体方式 |
| 不浪漫化 | 不写成美学、不写成救赎 |
| 不说教 | 不写成警示教育、不给后果加道德判词 |
| 不猎奇 | 桥段基数与其他轨道同档，不用它制造奇观段落 |
| 不用梗 | 全程平实中文（`lexicon.md` §7）|
| `kuaxingbie` 不设属性门槛 | 绑在"心低"上就是在病理化 |

死亡描写留在这一层：

```
✓  没有人第二天叫醒他。
✗  （任何具体描写）
```

复核方式：这三条轨道的全部文案由 §6 的判定问句**单独再过一遍**。

## 5. 真结局文本（C7）

**它不是"唯一真诚的声音"，它是唯一没有观众层的文本。**

叙述层通篇都是冷静客观的（§2），真结局用的是**同一台摄像机**，语气不变。
区别在于：别处的冷静叙述后面跟着一个分数，这里后面什么都没跟。
观众层整个消失了。

这比"忽然真诚起来"强得多——忽然真诚是在提示玩家"这段很重要"，
等于变相表扬，正是 C7 明令禁止的。语气完全不变、只是没人再打分，
那个空白自己会说话。

规范（在 §2 七条之上额外加严）：

- 平铺直叙的一个普通周二，具体、日常、无事发生
- **不出现**："其实" "原来" "终于" "重要" "明白" "值得" "好日子"
- 不回顾前半生。修仙、爆红、赔光——那些事就是没被提起
- 不用任何梗
- 无寓意、无升华、无点题
- 心理活动可以有，但只能是琐事级（`你想，鸡蛋裂了`），
  不得回顾、不得概括、不得抒情

参照：

```
✓  早上煮了两个鸡蛋，其中一个裂了。楼下的狗还是那只狗。
✗  他终于明白，这样的日子才是他一直想要的。
```

判定：把文本单独拿出来读，**如果它像一段人生感悟，就是失败的。**
它应该像一条平淡到有点好笑的朋友圈。

## 6. 基调判定问句

每条文案写完过一遍这三问，任一不合格就重写：

1. **BRIEF C7 的问句** — 玩家读完想转发的是"笑死"还是"我上了一课"？
   只有前者合格。
2. **市场部检测** — 这句话像不像一个市场部的人写的？
   像 → 重写（通常是因为用了黑名单里的泛梗，见 `lexicon.md` §6）。
3. **具体性检测** — 这条事件里有没有一个具体到有点多余的细节？
   没有 → 加一个。

## 7. C3 内容侧审查

BRIEF C3 的审查标准是机制层的，内容层的对应版本是：

> 这条事件的"糟糕选项"能不能在某种构筑下变成最优解？

一个健康的事件应该做到：从常人视角看，两个选项一好一坏；
从构筑视角看，"坏"的那个在吃污点的构筑里收益更高。

内容层不需要每条都满足，但**每个季至少 3 条要满足**，
否则数值上的解构（污点反转、腰斩变燃料）在文本层没有对应物，
玩家感受不到"游戏在鼓励我把自己搞烂"。

## 8. 禁用词表（叙述层）

**只约束叙述层**（事件正文、选项文案、死法、结局文本）。
观众层（短评、标签、腰斩通知）不受此表约束——它就是要有观点。

| 组 | 词 | 为什么禁 |
|---|---|---|
| 情绪定性 | 难过 崩溃 绝望 幸福 开心 痛苦 | 替玩家定性情绪，属于叙述者表态 |
| 价值判断 | 可悲 可笑 愚蠢 勇敢 值得 伟大 高尚 | 直接的道德评价 |
| 说教连接 | 其实 原来 终于 明白 领悟 才发现 | 点题信号词，一出现就是在讲道理 |

> **豁免词组**：`原来的位置` 这类里的"原来"是方位词，不是说教连接词，
> 属于误报。断言维护一张豁免表（`src/engine/seal.js` 的 `EXEMPT`），
> 命中豁免词组的部分先剔除再检查。
> 新增豁免必须是**语义确实不同**的词组，不能用来给点题句开后门。
| 吐槽腔 | 真是 居然 无语 | 把冷变成热，且是廉价的幽默 |
| 评论用法 | 离谱 荒谬 讽刺 | 作为**评论**时禁用；作为角色台词可用 |

三条使用说明：

1. **角色台词与心理活动不受词表约束的部分**：
   角色可以说"真是倒霉"，玩家可以想"值得吗"。
   受约束的是**叙述者**的句子（§2.8）。
2. **心理活动内部仍禁"说教连接"组**。`你想，原来这才是最重要的` 不行
   ——这是借内心独白点题，绕过规则而已。
3. 词表是下限不是上限。没在表里但在替玩家下判断的词，同样不许用。

### 8.1 做成自动断言

这条规范会随着内容量增长被稀释，所以**不靠人工核对**。

扫描 `content/events/*.js` 与 `content/endings/*.js` 的
`text` / `options[].text` / 死法文本字段，命中"情绪定性""价值判断"
"说教连接"三组词即报错。

排除规则：位于中文引号 `「」` `""` 内的内容视为角色台词或心理活动，跳过检查。
因此**写作时必须把角色台词和心理活动放进引号**，否则会被误报
——这个"误报"其实是有用的，它强制作者把叙述与引述分清。

对应断言编号见 `modules/09-vertical-slice.md` §4.11（断言 59–61）。
