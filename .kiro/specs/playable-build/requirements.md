# 需求：可玩构建（playable-build）

## 本文的定位

**本文不重述游戏设计。** 机制、公式、数值的唯一真相源是 `docs/`：

- `docs/BRIEF.md` — 硬约束 C1–C8
- `docs/SYSTEM.md` — 状态模型、脉冲循环、计分公式、季表
- `docs/modules/01–16` — 各机制细则
- `docs/content/` — 内容架构、梗词库、写作规范

本文只做一件事：**把上述约束翻译成可验证条目，并建立需求 → 验证手段的可追溯性。**

若本文与 `docs/` 冲突，以 `docs/` 为准；发现冲突应修 `docs/` 或修本文，不得两份并存。

验证手段的编号约定：

- `A#` = `docs/modules/09-vertical-slice.md` §4 的自动断言编号（1–76）
- `M#` = 同文档 §6 的人工验收编号（1–18）
- `T#` = 同文档 §5 / §5.1 的调参与平衡检查

## 3. 非功能需求

按"贵改的钉死、便宜改的不钉"原则，本节只钉**结构性**指标。
所有具体数值属于 `SYSTEM.md` §8 的待调参项，实测后回填，本文不复制。

| 项 | 要求 | 验证 |
|---|---|---|
| 启动方式 | `index.html` 双击即跑，无 npm install、无构建 | §7 完成定义 |
| 网络 | 运行时**零网络请求** | 人工：断网实测 |
| 模块形态 | 禁用 ES module（`file://` 下被 CORS 拦） | 结构约束 |
| engine 纯度 | `src/engine/**` 内**不出现** `document` / `window` | 静态扫描断言 |
| 内容形态 | `content/**` 必须可 `JSON.stringify` 往返（无函数/无 `undefined`） | 新增断言 |
| 帧率 | 手机竖屏实机 60fps，无明显掉帧 | M18 |
| 粒子上限 | 手机 600 / 桌面 1500，对象池复用 | `15-signal-fx.md` §3 |
| DPR | 上限 2 | 同上 |
| 动效 | 单次 ≤ 400ms（信号劣化 ≤ 800ms），**点击可打断**，无打字机 | M15 |
| 无障碍 | `prefers-reduced-motion` 生效；颜色非唯一信息载体 | M16 M17 |
| 存档 | `localStorage` 单键；损坏时静默重置并留备份键 | `06-meta.md` §5 |
| 浏览器 | 现代 Chromium / Firefox / Safari 最近两个大版本 | 人工抽测 |

> 完整 WCAG 合规需要辅助技术实机测试与专家评审，本项目只保证 M16 M17 两条基本项。

## 4. 内容与逻辑的边界

唯一保留的可移植性要求（Godot 版已推迟，本条凭自身价值保留）：

```
content/          纯数据。JSON 子集：无函数、无计算值、无 undefined
src/engine/ext/   带逻辑的扩展：effectOp / perCounter / titleSlot / reviewRule
```

理由不是移植，是**声明式内容 + 逻辑在引擎**这个边界本身更干净：
内容作者不可能误伤引擎，引擎改动也不会波及内容文件。

`14-content-api.md` §5.1 的带 `fn` 接口因此从内容层移到 `src/engine/ext/`，
注册 API 不变。

## 5. 范围

严格照 `docs/modules/09-vertical-slice.md` §2。本文不复制清单，只记边界原则：

- **A 期**：五季全流程 + 4 轨道 + 真结局 + 场景机制 + 三个新系统的 schema，
  内容量压到最小
- **闸门**：76 条断言全绿 + 调参与平衡检查达标 + 18 条人工验收 + 回填 `SYSTEM.md` §8
- **B 期**：内容量铺到首发列 + canvas 粒子 + 图鉴 UI + 分享卡导出

**明确不做**：账号、云存档、排行榜、服务端校验、玩家自制内容分享。
分数在客户端、改存档零成本，这是可接受的——本作没有竞技性排行，
真结局也明确不参与排行（`08-true-ending.md` §7）。

## 6. 需求变更纪律

本文与 `docs/` 的关系是**引用，不是复制**。

新增机制时的正确顺序：

1. 先改 `docs/`（正典）
2. 再在本文加一行追溯
3. 再在 `09-vertical-slice.md` 加断言编号
4. 最后写代码

跳过第 1 步直接在本文写机制细节 = 制造第二份真相源，后续必然漂移。
